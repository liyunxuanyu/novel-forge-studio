# 深渊一侧与星域观察者

- **名称**：深渊一侧（【生命】/「母亲」神血 / 神国 / 流变之物 / 深渊巨塔）＋ 星域观察者（【真理】国度）
- **类型**：种族 / 势力（外来存在与跨星域势力，非人类组织）
- **首次出现**：第130-131章（伊芙琳与纳尔）
- **结局状态**：第227章深渊巨塔前的漆黑「神明」被「天寂」相对论动能炮彻底崩溃，巨构成为下一阶段目标；世界任务「肃正？？？？」仍未完成

## 核心人物 / 存在

- **伊芙琳**：自称来自一个崇尚【真理】的国度，只为记录「灵域」在现实层面爆发后的完整演变过程；断言这颗星球终将沉入「灵域」、凌宇救不下这个世界；提出带凌宇离开被拒后留下「黑暗快要降临」的提醒凭空消失；随后在驾驶舱内向北极点黑暗投下捕获的「神胎」，扬言要带远征军回来。
- **纳尔**：撑黑伞的男人，伊芙琳的随从；对放任凌宇持保留意见。
- **唐海（「灵心」）**：灵心教核心，心脏具**二级神性**；本体第102章遁走后与乐天区血肉融合。
- **「天使」**：第210章被系统判为**五阶特殊变异体**；第149-150章以七八百米投影形态出现，核爆对其零伤害，凌宇判断那只是投影。
- **漆黑的「神明」**：第227章自巨构前方升起，喊出「献上虔诚者，将得洗礼」「不敬神者，当受永罚」，投出数百公里长枪，核弹对其无效。
- **秦风**：天才少年学者，提出「振荡期」模型；「避难所」计划中「文明精华筛选计划」的幕后理论提出者；下落原文未结算。
- **「母亲」与【生命】**：伊芙琳称人类是曾被【生命】眷顾、体内流淌「母亲」神血的生物；第180章北方【生命】残部出现。

## 立场倾向

- **深渊一侧**：以「洗礼 / 救赎」话语向全球传教（第208章引发跪拜潮），对不接受者施以「永罚」；黑潮自全球每一处海岸线同时上岸（第214章）。
- **星域观察者**：中立观察，不介入，只记录。伊芙琳在能级偏低时选择离开并留下「神胎」作为后续变量。

## 与其他势力关系

- **对曙光避难所**：终极敌对。第208-212章神国向全球传教并引发跪拜潮；凌宇以「清洗协议三，中子灭杀」清空神国军团、以「天火」行星歼灭炮击碎天体，第二座歼星炮补刀；第214-219章全球黑潮与天幕/星穹/天垣三系统对抗；第226-227章深渊巨塔前决战。
- **对古老贵族**：第178-180章古老贵族一方称寄生是「过去无奈之下的粗陋手段」；北方【生命】残部启动最终方案并召唤「圆成月影」，被一扇洁白巨门取代——洁白巨门与「圆成月影」是第181章之后的新线索，至全书结束未再结算。
- **对桂港异能联合救援协会**：第218章刘禹把黑液称为「流变之物」，判断它不受因果束缚、是概念层面的「变化」本身，并以异能压制其变化属性。
- **对北极**：第155-156章秦风团队在北极发现一个影子；第131章伊芙琳向北极点黑暗投放「神胎」；第196-207章北极「神明」被侵蚀、光门清场。

## 关键事件

- 第130-131章：伊芙琳与纳尔在乐天区战场边缘旁观世界终点；凌宇在琉璃焦土上识破两名外来者非人身份并遭近地轨道炮锁定；伊芙琳自陈来自崇尚【真理】的国度、留下警告后消失，并在驾驶舱内向北极点黑暗投下「神胎」。
- 第155-157章：陆震南口述深渊假说、振荡期模型、临渊计划与诛神计划的失败经过、北极影子上浮。
- 第191章：机关第二模态与全宇宙「涨潮」的读数被记录下来。
- 第192-195章：桂港近海巨怪一役与「是否真死」的疑问；海底龙尸与液态黑暗被记录；紧急会议给出样本结论与灾前猎龙线索。
- 第197章：「无神论的教义」开始建造；第197章支线任务十一「羔羊之罪」完成，获 30 万文明点，解锁「无神论的教义」建筑图纸（可对**七级及以下神性污染**实现区域屏蔽）。
- 第208章：「神国之匙」启动、神国显形，近地轨道攻防战；神国向全球传教并引发跪拜潮；凌宇发现靠近蓝星一侧有黑色物质缓慢侵蚀，判断对方状态不佳。
- 第210章：数以千万计的圣徒、牧者与天使自光芒深处涌出并集火母舰；凌宇启动「清洗协议三，中子灭杀」将其清空并轰击天体，获得击杀五阶特殊变异体「天使」的文明点与「反神谕」便携式神性污染抑制模块图纸；随后更多天使、七只千米级四翼天使与一批带伤巨怪接连浮现，四大洋升起数十根漆黑触手，一个上千公里高、戴黑铁冠的光之巨人自雾中飞出。
- 第211-212章：凌宇用「天火」行星歼灭炮击碎天体，又连发三发打爆从爆炸中心逃出、附身巨怪而成的近万公里发光人影，耗尽储备后当场具现第二座歼星炮补刀；神国覆灭后深海怪物疯狂登陆，世界任务仍未完成；【无神论的教义】在大气层高处摊开，灵域屏蔽升至 Lv.2 行星级覆盖。
- 第214-219章：全球黑潮、四十九根巨柱、淡金色天幕与千米级塔群、六艘「文明清洗者」、天垣行星级轨道防御阵列；苏晚用十二道翠绿光环设备净化黑液；刘禹压制「流变之物」；叶楚描述海底暗红色裂缝；「深渊行者」称号授予。
- 第220-222章：意识深处的低语自称「我就是你」，系统弹出「机械天灾」飞升猩红按钮；凌宇拒绝飞升并以亿万道并发指令碾碎异常代码与冲动源头；触发限时任务六「填渊」；确认桂港远海海底存在一道垂直裂缝般的时空隧道即感染源头。
- 第226-227章：试冲裂缝三秒内损失超过一千万架无人机、整体折损约百分之十，换来完整时空参数；六座蜂后平台建成直径超五公里的跃迁通道；水下「星海」实为无数发光怪物，深处矗立流淌黑液的金字塔巨塔；漆黑的「神明」升起，被「天寂」相对论动能炮彻底崩溃。
