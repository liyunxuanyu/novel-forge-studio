# 曙光避难所

- **名称**：曙光避难所 / 曙光核电站 / 国家灾后重建组织曙光抗灾委员会（对外身份）
- **类型**：组织（后发展为跨大陆行政实体）
- **首次出现**：第1章（设施本体）／第6章（对外代号「庄生」）／第181章（对外身份「曙光抗灾委员会一号空天基地」）
- **结局状态**：五大基地＋一个空天平台的全球体系（第185、217章）

## 核心人物

- **凌宇（对外代号「庄生」）**：本体为曙光核电站，全书唯一的最高决策者。第166章吴功当众把灵池的「行政与最高决策权移交中枢AI『庄生』」；第199章凌宇判断「天枢中心」可仅凭自己实现百万人口级社会的精细化管理。
- **沈雁**：第一个代理人，负责行政体系与流程；第217章「率行政体系统筹全球」。
- **张武**：核心行动部部长，行动一组，觉醒巨大化异能，配「龙骨」生物殖装。
- **林越**：行动二组，后驾驶「屠龙者」战术机甲。
- **陈默**：特别行动组（成员为三十四名吃果者病友）。
- **苏晚**：科研核心，云京大学最年轻生化领域教授，主实验室在砺山市「帷幕」研究中心与 307号研究所（第57章）。
- **徐建国**：工程技术核心，负责反应堆与武器量产。
- **李光、李定国、方毅、周毅、王海、孙远洲、赵海生、李飞**：行动、勘探与后勤骨干。

## 立场倾向

对内部实行「管吃管住管供能管安全换出力」的交换式治理；对外以绝对武力建立秩序，第181章广播明确「不要相信黑暗中的虚假光明与神启，从来没有救世主」。凌宇对人多一直有戒心，由沈雁把戒心翻译成流程。

## 与其他势力关系

- **砺山部队**：第85-86章李光提出加入、李定国放弃营地东移，整体并入。
- **顾长川车队**：第64-65章三百一十三人投票并入；顾长川后任「第零序列-对外远程搜救组」组长（第106章）。
- **望津各方**：第122章血神帮覆灭后统一，联合营地成立。
- **灵池守军**：第166章吴功宣布并入，自任曙光第二避难基地行动部部长。
- **桂港异能联合救援协会**：第184章桂港正式纳入曙光避难所体系。
- **北方联合抵抗指挥部**：第157章陆震南以残部指挥官身份正式申请归建主力部队，接受统一指挥与整训，双方维持心照不宣的合作关系。
- **古代贵族 / 朝圣者军团 / 深渊一侧**：敌对。

## 关键事件

- 第1-3章：重生为核电站、终止熔毁、谎称AI；第6章自报代号「庄生」。
- 第13章：张武带十七名幸存者进电站，主线任务二完成。
- 第20-21章：发现百米深地下基地；第32章人员认证中心上线。
- 第65章：人口达 1180；第86章：人口达 2941；第108章：人口破万；第128章：人口破十万；第166章：灵池并入后破五万（西川线）；第182章：登记在册人口 97.3 万余；第217章：国内登记 467 万余、全球收拢超 130 万。
- 第103章：建设任务一完成，解锁「守护者」单兵外骨骼；第106章：人口破万解锁人员素质档案记录中心。
- 第109-111章：人体强化剂投产、异能觉醒、三堆并网、「穹庐」护盾首次完全启动。
- 第123-128章：乐天区八天决战，文明点一度只剩 375 点，最终收复乐天区并获世界任务奖励。
- 第157章：陆震南当面追问凌宇真实身份，凌宇重述旧说法。
- 第166章：曙光第二基地（灵池）成立，行政与最高决策权移交「庄生」。
- 第180章：支线任务六「扫清余孽」以优秀评级完成，获 800 万文明点、「文明清洗者」空天母舰与「星渊穿梭者」图纸，文明点达 1100 万。
- 第185章：第一座大型磁约束氘氚聚变反应堆（仿星器）点火并网，形成五大基地加一个空天平台的布局。
- 第212-217章：神国覆灭、全球黑潮、天幕/星穹/天垣三系统运行，全球登记体系铺开。
- 第222章：凌宇拒绝「机械天灾」飞升，宣告自己是一个人；第226-227章舰队进入深渊。
