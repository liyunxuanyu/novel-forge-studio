# 背景设定

- 类型：平行世界（末世科幻）
- 覆盖范围：第1-227章

---

## 一、核心规则：末世成因

### 官方口径的灾难性质

第1章系统把危机定性为「**生化天灾**」。灾难爆发的具体日期原文未直接给出年份，但第126章出现「**晨曦历3056年12月末**」这一纪年写法。

### 灾变日的实况（第153章，郑北视角）

- 灾变日云京是晴空万里的好天气；云京外环突然堵车，前方三百米人群互相撕咬、被咬者十几秒后站起加入追逐；随后天幕变黑、连星光都看不见，云京陷入永夜。
- 同一时刻，**霖江地下指挥中心 05:41 沦陷并发生不可逆生物性污染**；此后以联合战略指挥中心名义发出的指令均不可信。
- 周靖远以联合战略指挥中心名义发出紧急通报：**「诛神计划」已确认失败**，参与者被称为叛徒；北方全域进入不可逆覆灭、建议南移；并声明「北方那东西不是神明」。

### 灾前线索：古迹、深渊与古老异种（第154-157章，陆震南口述）

- **古迹集中出现**：月球背面环形建筑与「神话生物」接连现世；专家一致认定古迹极大可能不是地球原有存在，且出现时间集中在**最近十年**、频率越来越高。
- **深渊假说**：学者提出超逻辑「世界」的假说，被联合科研组命名为「**深渊**」。
- **振荡期模型**：天才少年学者**秦风**提出，认为遗迹是外星文明沉入深渊后的残骸，神话生物则是基因上与蓝星高度一致的「**古老异种**」。现实稳定性若跌破阈值，蓝星将沉入深渊。
- 由此提出两项最高绝密计划：
  - **「临渊计划」**：以基因工程让人类能在深渊环境中生存，同时为对古代异种作战中受污染的老兵提供解法。陆震南本人就是望津林区对龙形生物作战的指挥官，患上龙鳞病与嘶吼后遗症，参与实验后成为同批唯一较成功的「适应」者，获得抗性与异能，而战友都变成怪物。该计划失败率近乎百分之百、死亡率九成，被叫停。
  - **「诛神计划」**：由各大国牵头组建跨国联合部队清除「古老异种」。秦风团队造出探测仪器，在**北极**发现一个影子，原定以核弹在其撕开裂口的窗口摧毁，但**核爆没有发生，那东西顺利上浮，一切崩溃**。
- 另有一项被叫停的**「避难所」计划**，其中包含「**文明精华筛选计划**」，其幕后理论提出者正是秦风。

### 「灵域」与星球沉没（第130-131章，伊芙琳口述）

- 伊芙琳自称来自一个崇尚【真理】的国度，只为记录「灵域」在现实层面爆发后的完整演变过程；
- 她断言**这颗星球终将沉入「灵域」**，并称这颗星球是「灵域」在这片边界星域的原爆点；
- 她称人类是「曾被【生命】眷顾、体内流淌『母亲』神血的生物」，接受「母亲」赠予的花朵、回归祂的怀抱是最温柔的结局，一切都会被血肉铭记，不至于在深渊下沉沦或在黑暗中被消解；
- 她留下「黑暗快要降临」的提醒后消失，随后向北极点黑暗投下捕获的「神胎」，扬言要带远征军回来。
- 第197章系统解锁「无神论的教义」建筑图纸，可对**七级及以下神性污染**实现区域屏蔽；第212章灵域屏蔽升至 Lv.2 行星级覆盖。

## 二、核心规则：感染机制

### 感染与丧尸化

- 被咬倒的人「挣扎不到十几秒就不再动弹，然后重新站起来加入追逐」（第153章）。
- 丧尸尸堆密度过高会催生突然死灰复燃的巨大变异体，云层中会出现飞行的巨型食腐怪物（第164章）。
- 第29章生物基因突变抑制剂确认对活人有效，成为队伍被咬后的后备方案。
- 第13章苏晚检测超市怪物肉块切片，结论是「最普通不过的人类体细胞」，线粒体、高尔基体与 DNA 测序都与人相同。

### 「神血」与容器机制

- **「上帝之血」异教传说**（第13章，苏晚转述）：信奉人类是上帝的孩子、上帝沉睡致人类神性沉睡，上帝醒来即审判日，未丢神血者褪去凡躯成天使，丢失者被抛下尘世挣扎，除非被神使点化而只能做仆从。该教派核心信徒多是顶尖生物医学高知，被国际刑警捣毁时暴露大规模非法器官移植——他们无移植疾病却在自己体内移植原始部落人类器官，法庭上称现代人类基因在退化，多一个原始野性器官就多一份保留神血、在审判日不被抛弃的机会。
- **古老贵族的容器逻辑**（第51章，程林自述）：自称与人类本应共生的古老种族，因「祂」的睡去而沉睡并高度劣化，用果子把孩子当幼年容器培养，聚落是养殖场。
- **苏晚的反转结论**（第84章）：它们其实很需要所谓「神血」稀薄的容器，人类不是被蔑视的「躯壳」而是极其珍贵的高质量容器，怪物嘲讽普通人「神血」消失殆尽其实是在说谎。
- **果实与异变血肉的对抗关系**（第84章）：程林的果实与乐天区血肉果实是同一种「古代贵族」胚胎幼体；果实与异变血肉是对抗关系；异变血肉只是初代宿主，而吞食果实的生物才是最终宿主。
- **辐射机制未查清**：第84章凌宇明确说辐射是激活还是重新赋予尚未查清。
- **神血全无者的假说**（第84章）：苏晚提出可能存在一种人体内「神血」已完全消失、即使被丧尸咬了都不会被激活变异——第95章叶楚即为此类案例（他免疫丧尸化却清醒目睹一切）。

### 晶体与晶体雨（望津规则，第120章）

赵四交代的三种晶体效果：

| 晶体颜色 | 效果 |
|----------|------|
| 白晶体 | 觉醒异能 |
| 红晶体、黑晶体 | 变怪物 |
| 绿色晶体 | 罗老大吃下后未变异且能力极强 |

- 罗一自述「第一个发现晶体可按特定颜色顺序服用」，两个月内成为望津最强（第122章）。
- 第94章苏晚的检测结论：蓝色晶体离区后自行崩解、不具传染性，但具有情绪放大效应，感染者颅内松果体附近有微型晶体增生持续发射规律电磁波。
- 第92章高远说明晶体化的两条途径与情绪失控的后果。
- 望津的特殊性：**只有望津使用异能会变强且听不到恐怖声音**（第120章，秦霄透露）。

### 信息素与抑制剂

- **「虚境1号」**：苏晚从三十四名吃果者体内分离合成，使丧尸无视人的信息素（第45章）；成为后期所有渗透与搜救的基础手段，队伍俗称「香水」（第57章）。
- **抑制剂**：可抑制感染变异并缓解异能后遗症（第164章空投淡蓝色抑制剂）。
- **高效组织修复剂**：用于治疗与维持生命体征（第102、103章）。

## 三、特殊设定：世界运转规则

### 永夜（第135、181、198章）

- 北方在灾变日同时陷入永夜；第135章陈默进入河朔市时「天空是压抑的深黑色，看不到太阳也没有星星月亮，属于物理意义上的光线缺失」。
- 第181章「世界在无预兆中陷入绝对永暗，气温骤降、风雪掩埋城市」。
- 第198章为「永夜第三十天」。
- 第96章叶楚描述：黑暗降临瞬间，「分界线像有人用刀把天空切成两半」，两人第一次重新看到阳光是在进入河朔市之后。

### 黑暗中的四条求生规则（第135章便签）

1. 不要相信在黑暗中走散后又归队的战友，除非他能当面生火；
2. 不要向有光亮的远处前进；
3. 尽量不要处在完全黑暗中；
4. 听到钟声响起立刻熄灭所有光源躲进绝对黑暗里。

- 第136章钟声突响触发第四条规则；第137章陆实交代：钟声后怪物自天穹落下巡视城市，任何火光都会被地下数层之外发现；钟声后第七分钟天使会洒下光芒。
- 第151章：以亲人面容出现的拟态怪物能改写体温与血液样本（血液先无细胞结构、后凭空出现红细胞），识破方式是让其当面生火。

### 黑潮 / 黑液 / 流变之物（第213-227章）

- 第213章：黑矛扎入金属后溶成黑液蔓延腐蚀合金；顾长川以极寒冰霜封堵失败、被反向侵蚀，遂命令全员避免物理接触、不要对黑液使用异能。
- 第216章：大洋深处「苍白死神」反物质轨道炮轰出的数公里凹陷几秒内被黑水回填，全功率输出被严重削弱。
- 第218章：刘禹把黑液称为「**流变之物**」，判断它**不受因果束缚、是概念层面的「变化」本身**，并以异能把手掌贴上容器压制变化，把黑液还原成一滩透明液体。
- 第218章：苏晚用十二道翠绿光环的新设备净化黑液，三分钟后沉淀出铁铜钛钨等十几种金属随机均匀混合、却恰好稳定的结晶体；二型「起源·改」净化效率比原版高三倍。
- 第195章：桂港巨怪不是龙、其细胞能反向同化龙血细胞；307号研究所怪物的细胞结构更接近桂港巨怪并夹杂类似「唯识花」神血序列的影响。

### 规则怪物（第186-188章）

- 规则怪物能越过「穹庐」护盾；曙光要弄清规则怪物入侵的原因与越过护盾的机制，凌宇正在汇总数据分析规律。
- 第186章「曙光日」当天夜间小巷中出现一个跪地求救的断腿人影，沈雁已识破死角矛盾。
- 第207章出现「流变之物」这一更明确的定名。

### 坐标跳变与空间畸变（第149、225章）

- 第149章：陈默车队驶过一个路口后道路与虚拟地图完全不同，凌宇发现车队从他的无人机视野中消失、哨兵视野出现错位断层；光点在距寒岭市区不到五十公里处坐标跳变、直接跳过了整座寒岭市区。
- 第225章：舰队接近目标后空间稳定性下降，海兽开始在净化水域内随机刷新；凌宇测算出时空畸变点。
- 第226章：试冲裂缝三秒内损失超过一千万架无人机，换来完整的时空参数。

### 「涨潮」读数（第191章）

- 机关第二模态与全宇宙「涨潮」的读数被记录下来。具体含义原文未明确。

## 四、特殊设定：文明跃迁系统的运作规则

- **宿主形态归类**：第1章系统把主角归类为「特殊异变类型2型——大型能源设施意识统一体」。
- **激活条件**：重生为设施后自动激活，给出任务列表（第1章）。
- **唯一货币**：文明点。获取方式为完成任务、保存知识、延续智慧体、恢复生产秩序（第1章）。
- **科技树**：一棵「倒长的巨树」（第9章）；节点需消耗文明点解锁。
- **蓝图与具现**：解锁节点得蓝图；蓝图可直接以文明点创造实体，这一动作称「具现」（第9章系统注明）。生物实验室标注「生化天灾特别优惠」（第9章）。
- **任务评级**：任务评级分「一般」「优秀」「卓越」；评级提升时「出现隐藏款图纸」（第60、82、89、128、180章）。
- **人口与成就联动**：人口突破一千、一万等节点触发系统奖励；收容未成年人超过二十位触发隐藏成就「童年」（第41章）；收容的幸存者自行设计出仿星器聚变堆方案触发隐藏成就（第132章）。
- **系统偏好**：系统对收容幸存者有「明显偏好」（第32章）。
- **系统认知边界**：第59章系统也有认不出来的怪物，凌宇为此震惊（原文写明「系统在他这里几乎无所不知」）。
- **「机械天灾」飞升选项**：第220章系统界面首次弹出猩红按钮，提示「机械天灾」前置条件已满足、是否飞升；第222章凌宇拒绝飞升。第69章凌宇曾打算「用增殖无人机做机械天灾」。
- **世界任务的收尾状态**：世界任务「肃正【生命】（1）」第128章以优秀评级完成；世界任务「肃正？？？？」至全书结束**仍未完成**。
