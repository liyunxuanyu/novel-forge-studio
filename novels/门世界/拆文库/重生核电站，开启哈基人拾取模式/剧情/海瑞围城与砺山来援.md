# 海瑞围城与砺山来援

- **类型**：主线
- **章节范围**：第80-89章（共10章）
- **概要**：尸潮在黄昏压上避难所。张武在火力高地指挥 122 毫米轮式火箭炮齐射，凌宇具现的八台声波共振抑制器让鸟形腐兽的音波失效，防空导弹与兵蜂接连拦截百眼与腐兽，最外围电网被尸堆压垮，八百米死亡禁区上八座「暴雨」速射炮塔把尸潮钉在高墙下；朝圣者突入后防空域被「雷锤」电浆炮气化，南岸水鬼与花鳄被「水手」机器人清剿。随后黑翼以浓雾形态重返战场并显出暴涨后的血翼身形，凌宇用刚解锁的便携型神性屏蔽仪全员配发、再以二十架长空之刃集火；地下虫群掘进被王海的「穿山甲」与炸药瓦解，地渊百足被掀出后遭全部火箭炮集火。与此同时林越、陈默率近一半装甲车队绕行汇宁区抵达海瑞生物周边，用五千架增殖无人机倾泻火力。第 81-82 章攻坚炸开大楼外层，露出内部血肉卵囊与直径超十米的巨型胚胎，肉毯硬挡三千架兵蜂并以血色触手击穿无人机，凌宇投入一万架待命自爆无人机把方圆数公里的苍白雾气吹散；血翼试图回援被一架引擎过载的长空之刃自杀式撞停，两千多架兵蜂随即在半空引爆、炸掉它的鳞翅并逼它朝避难所壁垒冲锋，沈雁拒绝撤退、用炮台近距离击碎其上半身、以高能激光汽化下半身，系统判定击杀三阶特殊变异体「03型虫甲嵌合兵器」。胚胎却在爆炸后裂开，一名身高超过二十米、无头而面部为嘴眼莲花结构的血肉怪物站起，吞噬丧尸持续膨胀到二十五米并追击车队，凌宇的蜂群被其血丝成片击落、爆炸只能换来不到两秒停滞；危急时砺山部队的 PHL-191 超视距火箭弹命中怪物救下车队，砺山主力入场后战局逆转，怪物剥离血肉披风化为晶象怪物牵制郑海部队，本体冲电站，被两万架自爆无人机炸成焦黑残躯后由郑海部队与无人机补刀击杀。第 83-86 章战后转入清理：分区焚烧变异体尸骸、二次肃清安澜区、赴海瑞生物废墟采样、清理地下虫群并布设净水设施；陈默的特别行动组按无人机追踪逐个点杀逃跑的「古代贵族」，但支线任务六仍显示未完成，凌宇判断余孽远不止远江这些。砺山部队营长李光与凌宇对话，追问凌宇对谁负责，凌宇答只对自己负责；李光提出加入并获得全面迁移支持。地下 C 区新出现的「穹庐」护盾发生器因发电量不足无法开机，徐建国与赵海生震惊；凌宇解释核电站也有功率上限、全激活护盾就得停掉其他设备，请徐建国研究能耗更低的「青春版」，徐建国看完图纸坦言完全看不懂、技术代差太大。第 85-86 章庆功宴上李光称这里才是人类的希望，砺山据点郑海报告团长李定国要求见庄生，见面时凌宇直接告知砺山中心出现异常浓雾、必须紧急转移；李定国当即下令放弃营地东移，十分钟内完成撤离，次日一千两百多名幸存者在近两百辆车与上千架无人机护送下抵达避难所，全程四小时半无一人伤亡，三天后避难所人口达到两千九百四十一人，李定国任行动部副部长。第 87-89 章转向新的敌人：凌宇整理腐兽档案，苏晚实验室查明怪物本质是巨型真菌聚合体，李定国介绍砺山中心的蘑菇后凌宇派出四百架无人机进入浓雾侦察，发现雾中飘着暗红色孢子、普通丧尸被菌丝寄生并被腐兽大量捕食、市中心菌盖呼吸式喷发孢子；会上苏晚提出真菌是统一的高智慧集合体并主动设计、迭代生物结构，沈雁反问真菌本身可能只是它模仿的第一个形态，苏晚当场改变研究方向冲回实验室。第 88-89 章避难所完成进攻准备，先以喷淋与吸风无人机压低孢子浓度，再以三千余架自爆无人机引爆市中心菌宇，地面火箭炮、榴弹炮与六门电浆炮随即开火，系统下达限时任务五「腐土焚净」；另一线王海勘探组打通地表通道，陈默与顾长川带队进入新洲区回收资料，发现蓝色晶体异常并在冷湖研究院撞见沉睡的水晶巨蟒。苏晚在指挥频道提出反常识结论：腐肉菌菇对纯动能、高热与激光适应迟缓，且尚未「醒来」，因此可以人为干预其自然选择；张武调整火力，凌宇标出三处弱腐兽区域加以保护、对强攻击性个体定点绞杀，三十多个小时后腐兽小型化、无害化，第五天收官，限时任务五以「卓越」评级完成并触发隐藏成就。
- **起始目标**：凌宇要守住避难所、摧毁海瑞生物这一传播源头，并把砺山方向的幸存者与部队整体接收进来
- **主要阻碍**：尸潮、黑翼、地渊百足三线同攻；海瑞生物的胚胎与二十米血肉怪物恢复力极强，常规火力只能换来不到两秒停滞；砺山中心被异常浓雾与腐兽占据，重炮、凝固汽油弹、地下爆破都无法清除；穹庐护盾因发电不足开不了机
- **关键变化来源**：沈雁拒绝撤退并近距离击碎血翼上半身；砺山部队以 PHL-191 超视距火箭弹救下车队并主动并入；李定国十分钟内下令放弃营地东移；苏晚提出以人工干预自然选择的方式驯化腐兽
- **局面变化**：避难所完成从「据点」到「区域中心」的跨越，人口达两千九百四十一人、拥有正规部队编制与行动部；海瑞生物被摧毁但源头性质被定性为外来生物；腐兽从威胁变为可驯化资源并被封存在一号收容舱作诱饵与研究样本；新洲区与冷湖研究院成为下一阶段目标
- **得失与承担者**：避难所得到部队、人口、帷幕要塞级异常收容研究中心与腐兽样本；代价由沈雁（近战硬抗）、林越与陈默车队（被二十米怪物追击）、砺山守军（弃营）承担；凌宇承担了把二十米怪物主动引向电站的风险
- **后续影响**：砺山部队与李定国是后续西南、北方各条战线的主力；「帷幕」研究中心成为后续晶体与强化剂研究的基地；一号收容舱的腐兽样本与苏晚的「外来生物」判断为深渊真相提供关键旁证
- **关键信息功能**：披露腐兽是巨型真菌聚合体、可能是外来生物；披露海瑞生物大楼内存在血肉卵囊与巨型胚胎；读者知道支线任务六未完成意味着古老贵族余孽遍布全国，角色们只知道远江已清
- **读者需求**：看三线同攻的决战规模；看主角用两万架自爆无人机这种量化手段解决问题；看新势力主动投靠的认可感
- **情绪模块ID**：
- **套路框架位置**：第三幕开场，把全书从「一个据点」推到「一支军队」
- **桥段标签**：绝境翻盘、越级战斗、护短打脸、围观震惊、任务奖励
