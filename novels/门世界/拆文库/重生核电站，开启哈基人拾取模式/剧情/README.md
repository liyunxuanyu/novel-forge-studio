## 覆盖与遗留

第 1-227 章全部落入上述 23 个单元，无未分配章节。相邻单元之间存在 1-2 章的过渡重叠（如第 80 章同时承担尸潮决战的开场与海瑞围城的起点、第 90 章同时承担砺山战役的收束与新洲晶体的开场），已在各单元的结构分布中注明。

散落情节与待复核项见 [故事线.md](故事线.md) 末尾「待聚合」一节。

## 剧情单元覆盖重叠（已披露）

- **本目录 23 个剧情单元中，2 处章节区间交叉。**

| 重叠区间 | 与之交叉的单元 |
|---|---|
| 第35-45章 | `避难所建设与自给自足` |
| 第46-48章 | `汇宁攻坚与地下收容` |

- 成因：这几条故事线在同一段章节里交织推进，先建的宽口径单元与后切出的同级单元没有对齐区间。
- 影响：全书 227 章仍被完整覆盖、无缺口；重叠处的剧情描述互相印证、不矛盾，不影响按章节检索。
- 处置：保留现状并披露，不回改。
