# 乐天区全面战争

- **类型**：主线
- **章节范围**：第106-112章（共7章）
- **概要**：避难所人口以日均至少三位数增长，沈雁忙到靠高效组织修复剂硬撑。人口突破一万触发系统奖励，凌宇解锁「人员素质档案记录中心」，用它一天内重筛现有人员并处理十几个有提示者；对蛮横、阳奉阴违与想夺权的人则按临时条例驱逐、监管、设庭处置，秩序重归平稳。顾长川的「第零序列」报名截止收到两千一百三十七份申请，最终精选一百五十人外加叶楚、秦蕊两名特殊随行人员，车队满配装备与无人机；出发前张武送别、林越远程提醒别立 Flag，顾长川报出队伍称号「旅者」。第 107 章乐天区的异常雾区向安澜区方向偏移约三百米后停下，无人机未第一时间察觉；凌宇报告血肉组织已几乎覆盖全部建筑、普通丧尸被几种全新血肉变异体取代，张武建议把两区交界线设为一级警戒并承诺尽快拿出防御反攻预案，与会者一致同意。次日避难所全面加速：临武市幸存者加速并入、智力受损者集中安置在 D 区改建的看护楼层，林越在长洲市以三十六辆主战坦克与上万架无人机组成的金属乌云数天肃清大型变异体并救援幸存者，李光完成钢山市扫尾后西进白山市，张武着手构筑新防线；远江市外围开始有持卡幸存者陆续抵达安澜区哨卡。第 108 章人员素质档案记录中心投入实战，对蛮横、想夺权者按临时条例驱逐、监管、设庭处置；第零序列精选一百五十人成军。第 109 章苏晚在砺山市帷幕异常收容研究中心用变异体实验数据、冷湖研究院韶光实验室旧数据和腾蛇样本完成人体强化剂，当众自我注射并说明效果与副作用；凌宇给出合成优化方案，两条产线确定同步推进。一周后一百五十二名「第零序列」成员完成注射，顾长川在开水间接热水时觉醒冷冻异能，全套检查无法解释，他本人与苏晚、凌宇商定再观察一周，确认能力可控且只有他一人出现后，车队补充燃料向西南出发。第 110 章避难所按荣誉值排定第一批两百人注射名单，标准型药剂产线稳定运行；核心行动部部长张武注射后觉醒巨大化能力，力量数据再涨近八成但维持不足五分钟、且「破晓」装甲不能随体型变化；凌宇取出闲置的「龙骨」生物殖装战术框架图纸并花五千文明点具现，张武试穿后维持时间延长到一小时四十七分钟。深夜沈雁追问乐天区最坏情况的兜底手段，凌宇答无确保消灭手段、只能疏散，并被打断了对电站意义的追问；李光与林越报告白山市肃清、长洲铀浓缩厂可复工。第 111 章长洲方向第三批燃料车队抵达避难所卸货区，凌宇因冷湖研究院资料录入而自动解锁高温气冷堆、热谱钍基熔盐堆、钠冷快堆三项技术并获得一万三千五百文明点；徐建国震惊于凌宇给出的可施工方案，却又感叹建成新堆需两三年，凌宇告知新设施已激活，方案为十座铅冷快堆、四座热谱熔盐堆与高温气冷堆模块集群；数日内铅冷快堆率先热态调试并投运、熔盐堆与高温气冷堆相继并网，旧八台压水堆分批停堆大修；远江初雪时「穹庐」护盾因能源升级完全启动笼罩安澜区。第 112 章行动二组收复震州后，林越率队压制一只伪装成幸存者的「古代贵族」，它随人群领物资、吃热饭、聊天，直到医疗组采血才暴起伤人；面对质问，它自称提供过「庇护」、声称寄生对象与自己本是一人，并喊出「花要开了」。林越将其击杀，随后确认乐天区方向已出现试探性攻击，张武在安澜区与乐天区边界用龙骨殖装清剿十七只「肉蕾」，凌宇的蜂巢平台建成并向乐天区放出上千架自爆无人机。
- **起始目标**：凌宇要在乐天区威胁爆发前完成人口整编、武装强化与能源升级，并把第零序列远征队送出去
- **主要阻碍**：人口破万带来的筛查与安置压力，出现想夺权与阳奉阴违的人；乐天区异常雾区向安澜区偏移、血肉组织覆盖全部建筑并衍生新型变异体；强化剂引发的异能原理无法解释，张武的巨大化能力有明确时限；凌宇自己承认没有任何已验证手段能消灭体型超过两百米的存在
- **关键变化来源**：沈雁以高效组织修复剂硬撑并推进整编；苏晚当众自我注射强化剂；顾长川与张武在注射后觉醒异能；凌宇用五千文明点具现龙骨殖装解决张武的时限问题
- **局面变化**：避难所人口破万并拥有制度化的人员素质档案；标准型强化药剂产线铺开，两名核心干部获得异能；高温气冷堆、熔盐堆、快堆集群投运，穹庐护盾首次完全启动；乐天区从隐患变为已开始试探性攻击的战场，蜂巢平台与上千架自爆无人机投入反攻
- **得失与承担者**：避难所得到能源自由、异能战力与治理工具；代价是旧八台压水堆停堆大修、强化剂的副作用与异能成因不明；凌宇承担了「没有兜底手段」这个事实被沈雁知道的压力
- **后续影响**：强化药剂与异能体系是全书后续战力的主线；龙骨殖装成为张武的专属武装；乐天区战事在第 112-134 章持续升级；第零序列远征队引出西南远征线
- **关键信息功能**：披露强化剂能诱发异能但原理不明、且副作用机制不清；披露乐天区存在体型预估超两百米、拥有未知能力的怪物；读者知道凌宇对沈雁隐瞒了关于电站意义的追问，角色们只听到「只能疏散」
- **读者需求**：看主角势力跨过万人口与能源门槛；看核心干部获得异能的名场面；看大战将至的压迫感

- **套路框架位置**：第三幕中段，把「经营」推向「制度 + 异能 + 能源」三重跃迁
- **桥段标签**：面板升级、技能点亮、攒钱起家、任务奖励、护短打脸
