## 可复现模块卡

### EM-001 个人奇遇转国家工程的验证与授权链

| 字段 | 内容 |
|------|------|
| 读者想看什么 | 想看到"我手里的东西是真的、而且有人比我有能力用它"的双重安心：既被承认不疯，又被免掉独自承担世界的重量；同时享受一次外行用硬数据把内行专家压到改口的优越感 |
| 情绪链 | 误判与被制服（恐惧·屈辱）→ 拿物证反问（紧张·反攻）→ 仪器数据自证（震动）→ 权威层逐级上报、停机让路（敬畏）→ 定调立项、授予权限（热血）→ 立刻被告知"你是唯一窗口也是唯一弱点"（寒意）→ 带着新身份走进权力中心（使命感） |
| 戏剧单元 | ①闯入权威机构报告，被当成威胁物处理；②抛出实物证据，却被设备读成灾难级读数，处境更糟；③不辩解，只把检测报告反问回去，逼权威改口；④二次取证成功，证据链补全（可复现、可实测）；⑤跨学科复核与会议辩论，中途被叫停项目的人成为证人；⑥最高层定调立项，把奇遇写成国家级计划；⑦授予当事人权限与身份，同时公开点出他的不可替代与不可替换；⑧以军礼／任命／入场的仪式收尾，故事从个人线转成国家线 |
| 可替换项 | 个人奇遇物→任意"无法伪造的可验证物证"；军事基地→任意"把私人异常当公共安全事件处理"的机构；防化兵误判→任意"检测手段本身给出灾难级结论"的反向打脸；S级绝密项目→任意"资源倾斜＋保密等级"的立项形式；"唯一窗口即唯一弱点"→任意"核心资源与单点风险绑定"的公开隐患 |

| 成立条件 | 物证必须客观可验证（不能靠口述说服）；权力层必须既有怀疑者也有敢担责者；主角必须主动放弃独占，否则"转成国家工程"不成立；验证环节必须有人被"叫停既得项目"付出可见代价 |

### EM-002 技术代差碾压与围观者认知崩塌

| 字段 | 内容 |
|------|------|
| 读者想看什么 | 想看"我熟悉的常识在对方眼里是神迹"的错位快感，以及权威者亲口承认自己那套体系失效时的解气；核心动机是被验证的优越感加上一次安全的、不流血的碾压 |
| 情绪链 | 轻蔑与质疑（俯视）→ 首次接触的困惑（不解）→ 单一现象打破经验（惊疑）→ 亲手验证失败、反复重试（挫败）→ 承认原理无法理解（崩塌）→ 转向求购／求教／改宗（臣服）→ 立刻发现自己买不到、学不会（依赖与无力） |
| 戏剧单元 | ①对方以旧权威身份公开轻视新事物；②第一次接触出现"与经验不符"的小现象，被解释为巧合；③当事人亲手复现并失败，出现第二次更硬的证据；④追问原理被拒或听不懂，认知开始松动；⑤当场演示的压倒性效果（一击／一测／一炮）摧毁对方阵营的自信；⑥对方内部出现分裂：一部分要买、一部分要封杀、一部分要仿造；⑦求购环节暴露门槛（产能、后勤、原理），臣服变成依赖；⑧以对方阵营的失语、破防或改口作结 |
| 可替换项 | 大夏工业品→任意"体系化产出物"；异族旧权威（工匠／教会／贵族／老将）→任意"靠传统经验立身的话语权持有者"；武器展销会／靶场演示→任意"公开可复现的展示场合"；"后勤皆兵"式判定→任意"从单件神器看出体系门槛"的洞察句；CPU 盖板／电路板→任意"无法逆向的底层工艺壁垒" |
| 不可照搬 | 人名：艾尔德、芬朵娜、索林、格罗姆、凯尔、木语长老、瓦雷留斯、格伦长老、矮人王、教皇格里高利七世、亚迪斯；地名：泰拉、艾维诺尔、翠叶之城、洛丝缇亚、矮人山城、萤叶镇；装备／技术：复合弓、连弩、加特林、云爆弹、155 榴弹炮、立方氮弹药、陆盾 2000、盘古机甲、鲲鹏运输机、三相电、万用表、减重符文、悬浮符文；台词："不能互换即一次性用品""可以是可以""六倍伤亡比""后勤皆兵"；具体事件顺序：第21章齿轮装不进卡榫→第25章附魔复合弓穿透结界→第161章战报压垮矮人→第288章撬开 CPU 盖板集体破防→第411章一拳打爆拳力机 |
| 关键触发物 | 一件能让对方当场亲手验证并失败的成品；一组硬数据（伤亡比、击穿深度、读数）；一个让对方无法回避的公开场合 |
| 必要铺垫 | 必须先写足对方的自信来源（手艺、神权、战功），崩塌才有重量；必须提前给出碾压方自己的限制条件（产能、后勤、不可复制），否则后文依赖感没有根；演示场合必须有第三方见证者 |
| 成立条件 | 对方必须是被"自己验证"说服的，不能被说服；碾压方必须同时暴露门槛，否则会退化成无成本开挂；崩塌后必须给出对方的替代路线（仿造／改宗／采购），否则阵营线断掉 |
| 复现步骤 | 1. 建立对方以旧体系为傲的自信；2. 抛出一个"不符经验"的小现象；3. 让对方亲手复现并失败；4. 追加第二次更硬的公开证据；5. 追问原理，得到听不懂或不愿说的答案；6. 用一次压倒性演示完成认知崩塌；7. 让对方内部就"买／仿／封"分裂；8. 在求购环节暴露门槛，把碾压转成长期依赖 |
| 失效情形 | 对方一见面就跪；只有一次演示没有反复验证；碾压方零代价零门槛；崩塌后没有后续路线，阵营反应只爽一章就消失；把技术写成玄学（无法给出任何可检验的说法） |
| 反例/边界 | 不要写成"敌人都是蠢货"。本书的边界是：第21章先让林默自己教不出标准化（画不准一厘米）、先承认自家体系也有说不清的地方；第161章压垮矮人的是自家战报的伤亡比，不是大夏的宣讲；第288章破防后立刻给矮人一条改走魔偶路线的出路，避免崩塌写成单方面羞辱 |

### EM-003 两界社会互看造成的常识落差与荒诞感

| 字段 | 内容 |
|------|------|
| 读者想看什么 | 想看"我的日常在别人眼里是奇观"的双向反差带来的笑点与优越感，也想借外来者的眼睛重新发现被自己忽略的生活质感；动机是安全范围内的文化冒险与自我确认 |
| 情绪链 | 好奇与轻慢（游客心态）→ 认知错位引发的滑稽（好笑）→ 沉浸式消费与体验（愉悦）→ 价格／规矩造成的阶层尴尬（窘迫）→ 被陌生人的善意接纳（温暖）→ 发现自己这边也有人羡慕对方（反转的敬意）→ 用一句朴素的对比把优越感翻面（沉思） |
| 戏剧单元 | ①开放一个名额稀缺的跨世界入口，制造"多数人只能旁观"的稀缺感；②第一批外来者以参观者身份进入，语言／货币／规矩全部不通；③用小额消费触发连锁抢购，证明价值观差异就是商业机会；④安排一次"技术小物解决生活麻烦"的体验，让围观者当场排队；⑤让外来者进入本地人的家庭／学校／工地，看见与自己社会结构的根本差别（教育、阶层、保障）；⑥本地人也在羡慕外来者的某些东西（闲适、纯粹、信仰），完成双向打量；⑦用一句外来者的评价句把制度对比点破；⑧在最温馨处被一条紧急军情打断，把日常线拽回主线 |
| 可替换项 | 跨世界旅游名额→任意"稀缺准入资格"；异族商业街→任意"跨文化消费场景"；翻译耳机→任意"沟通降级装置"；符文护臂／祈愿裙→任意"异界小商品"；"全民上学"式制度对比→任意"对方社会无法理解的基础制度"；最高级别警报→任意"在情绪最高点切入主线的打断装置" |
| 不可照搬 | 人名：张兮兮、米娅、卡桑、木语长老、凯尔、格罗姆、索林、安妮、维恩；地名：泰拉、两界贸易中心、星语林、天枢城商业街、圣光之城、中央生态公园；物件：净化胸针、祈愿裙、炖果、月露果、阳歌果、常青藤链、叶语项链、翻译耳机、臭豆腐、冰淇淋；台词："这里是我们的家""太爽""文化才是最快的刀子""地表无法居住"；具体事件顺序：第402章参观地下城集体石化→第415章博物馆被小吃冲击→第504章六亿抢一万名额→第508章手机悬停引爆排队→第517章树人托举时警报响起 |

| 必要铺垫 | 必须先立好两个世界的物资差距与制度差距，落差才有来源；必须提前埋好战争威胁，日常线才能被有效打断；视角人物必须是普通人，不能是决策层 |

### EM-004 战后结算与敌产转化

| 字段 | 内容 |
|------|------|
| 读者想看什么 | 想看打赢之后的"收账环节"也能占尽便宜：不是抢，而是用规则、折算和账户把对方的旧怨一次性清空；动机是秩序感与掌控感——暴力已经结束了，剩下的事由会算账的人决定 |
| 情绪链 | 胜利后的疲惫（松弛）→ 双方同时提相反诉求（僵持）→ 结算口径全不清、清单越摆越乱（烦躁）→ 幕僚方案被否、局势卡死（憋闷）→ 用现代结算工具提出第三方案（机敏）→ 对方最激烈的人当场反驳（对抗）→ 用一次体验让对方自己改口（畅快）→ 追加补偿并达成共识，再补一句私下道歉（满足与温软） |
| 关键触发物 | 一份双方都不认账的清单；一套现代结算工具（折算、账户、账期）；一个需要被安抚的核心盟友 |
| 必要铺垫 | 必须先有"打完之后谁来收尾"的制度真空；必须提前给出对方的损失（矿脉、熔炉、伤亡），否则退让没有动机；主角手里必须有一件对方想要的长期供给品 |
| 成立条件 | 结算工具必须比"给钱"更高级（账户、配额、分期）；必须有一方当场被说服而非被压服；必须给让步方留一条可期待的下一次 |
| 复现步骤 | 1. 战争刚停，双方同时提出相反诉求；2. 摆出双方损失清单，暴露结算口径不统一；3. 参谋／幕僚抛出两个方案都被否，逼出第三方案；4. 用折算与账户余额替代实物退还；5. 让最激烈的一方当场反驳"花不完"；6. 用一次生活方式体验让对方改口；7. 对方追加补偿，短时间内达成共识；8. 用一句私人口头上的道歉／承诺收尾，把制度结算软化成关系 |
| 失效情形 | 靠主角一句话压服全场；结算细节全靠旁白；没有对方损失的具体数字；盟友的改口没有中间步骤；把结算写成单方面占便宜 |
| 反例/边界 | 不要写成"打赢了就都归我"。本书的边界是：第469章先让智囊团否掉两个方案才定案，说明结算本身是技术活；第470章让盟友当场提出退人退物、主角只拒退物资，是局部让步而非全拒；第471章用半小时达成共识并补一句道歉，避免把外交写成压榨 |

### EM-005 文明级结算与坐标成为商品

| 字段 | 内容 |
|------|------|
