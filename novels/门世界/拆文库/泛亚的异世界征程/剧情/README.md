## 覆盖与遗留

第 1-366 章全部落入上述 45 个单元，相邻单元之间**没有过渡重叠**：前一条的结束章 +1 即后一条的开始章（唯一例外是第 61 章单独立为一条，因为矮人矿石谈判与帝国朝堂转向是两件互不依赖的事，并置会让任一条的目标不成立）。

本书是群像式文明碰撞，作者声明没有绝对主角，视角在多个国家与人物之间切换，因此剧情单元按「同一场危机／同一项工程／同一次政治变动」划分，而不是按主角的成长阶段划分。一条单元可以由同一场危机的多个视角共同构成。
