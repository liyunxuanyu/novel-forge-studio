### EM-001 越级打击与围观者认知崩塌

| 字段 | 内容 |
|------|------|
| 读者想看什么 | 想看「一方完全看不懂另一方」时被当场打碎世界观的过程：不是看谁更强，而是看**弱势方的自信判词如何被一件实物当场推翻**。读者要的是「碾压」与「认知崩塌」两件事同时发生，并且崩塌者必须是此前最笃定的那个 |
| 情绪链 | 强势方的规则展示（朝贡、贵族礼仪、法术分级）→ 弱势方的轻慢与误判 → 一次具体实物介入（一架飞机、一门舰炮、一台机甲）→ 打击落地的爽感 → 见证者当场失语/跪地/嘶吼「千万不要去」→ 同一批见证者被迫重估整场战争 → 章尾抛出「这还不是全部」的更大层级 |
| 戏剧单元 | ①强势方在公开场合展示自己的规则并当众贬低对手（把无魔力者判为蛮夷）；②对手按旧规则自信下令（用血瞳、用占卜、用旧军情推算时间）；③一个具体物件或单位出手，用**可度量的数字**把代差写实；④打击落地，读者先看到结果、角色后知道原因；⑤让一名有权威的旁观者当场被击穿认知（学者、将军、贵族）；⑥把这次打击兑换成制度或战略后果（出兵决议、封锁、宣战）；⑦章尾留下更高层级的力量未出手 |
| 可替换项 | 代差载体→任意技术体系（航海、火器、蒸汽、航空、电磁、生物）；被碾压方→任意依仗旧规则的强权（帝国、教会、贵族议会、超凡者行会）；见证者→任意有权威且此前最笃定的中立角色（学者、占卜师、老将军、外交官）；规则展示场→任意公开场合（朝堂、宴会、港口检查、议政大殿）；度量方式→任意可心算的标尺（射程、速度、功率、续航、每分钟发射数）；认知崩塌的落点→任意一句自我否定的判词 |
| 不可照搬 | 原书专名与具体设定：林远征、王伟、苗玉城、特利尔、艾丽莎、迦兰斯、马克西米利安、赫凡特、薇薇安、奥尔特、特拉法尔、阿图斯·雷恩、哈德良·瓦莱里乌斯、瓦努斯、艾赛罗斯、纳赫特玛；共识号、威尔特号、福建号、湖南号、海燕号、阿克琉斯号、铁崖号、帝国之刃号；赤水港、奥伦港、安德拉港、沙勒曼岛、诺尔丁城、黑油城、萨普塔吉里、鹰嘴崖、流沙谷；先锋-1 型／K1 型 35 毫米突击步枪、鹰击-21、霹雳-17、红旗-9B、长剑-100、匕首、伊斯坎德尔、东风-15／东风-61D、MA32、M15、伯格利 A 型、A2／A30；具体事件顺序：先接触救人→再组建使团→再海上遭遇战；标志性台词：「我们不开第一枪」「千万不要去」「上帝啊」「何人胆敢，窥视天庭」 |
| 关键触发物 | 一件可被当场看见的实物（雷达屏、火炮铭牌、机体、无人机）；一份敌方亲手写下的误判记录（侦察报告当误报、旧军情推算表、占卜幻象）；一句被反复引用的权威判词；一个能算出倍数的数字（0.7 马赫、五十公里射程、每分五百发） |
| 必要铺垫 | 必须先让强势方把「规矩」完整展示一遍，读者才知道这套规矩有多重；必须先让弱势方在同类场合吃过一次亏（受检、被勒索、被嘲讽），落差才有支点；代差必须在前文以参数或实物出现过一次，否则第一次登场会被读成外挂 |
| 成立条件 | 代差必须**可度量且稳定**——不能随剧情需要忽强忽弱，否则读者不再信任后续的胜负；必须有一名活下来的见证者把认知崩塌讲出来，纯全灭的打击没有情绪落点；弱势方的误判必须是**他自己用规则推出来的**，而不是作者硬塞的愚蠢 |
| 复现步骤 | 1. 用一场公开的规则展示把强势方的自信坐实（朝贡、法术分级、贵族礼仪、军情推演）；2. 让弱势方在同类场合先吃一次小亏，把落差支点立起来；3. 引入一个具体物件或单位，用数字或铭牌把它的能力写实；4. 让对手按旧规则自信下令，把「误判」写成他的推理过程；5. 让打击落地，并让一名有权威的见证者当场被击穿；6. 把这次打击兑换成制度或战略后果（决议、宣战、封锁、加冕）；7. 章尾留下更高层级的力量未出手 |
| 失效情形 | 代差方一出手就结束、没有弱势方的判词作对照，读者只觉得是杀鸡用牛刀；只写结果数字不写误判过程，认知崩塌就变成作者宣布；被碾压方没有一名见证者活下来，后续无人替读者说出「我们错了」；每次打击都比上一次大一级却不给读者重新校准的机会，会滑成数值通胀 |
| 反例/边界 | 不要写成单方面屠杀。本书反复插入敌方基层视角（第 15 章兽王回望山崖、第 42 章特伦斯扛着昏迷战友一步一步挪、第 54 章伦德尔裤子上全是尿骚味），把「碾压」写成有代价的胜利；也不要把弱势方写成愚蠢——瓦努斯明知护不住还违令上塔顶、哈德良只剩一小半战力才撤退，双方都在自己的规则里做了正确判断 |
| 关联节奏 | 节奏.md AX-105（第 16-18 章，事件 3/5、情绪 4/5、篇幅 3/3）、AX-107（第 21-24 章，事件 5/5、情绪 5/5、篇幅 3/3）、AX-111（第 37-41 章，事件 5/5、情绪 5/5、篇幅 3/3）、AX-203（第 66-67 章，事件 5/5、情绪 5/5、篇幅 3/3）、AX-204（第 68-73 章，事件 5/5、情绪 5/5、篇幅 3/3）、AX-304（第 137 章，事件 5/5、情绪 4/5、篇幅 3/3）；爽点循环 SL-103、SL-104、SL-201、SL-202；情绪触动点 TP-104、TP-106 |

### EM-002 两界差价与规矩滞后

| 字段 | 内容 |
|------|------|
| 读者想看什么 | 想看「钱能算清」带来的确定性爽感：一件在一界不值钱的东西，在另一界是天价；想看两个语言、货币、法律都不通的商人怎样从各报一个价、谁都不肯先交货，一路谈成一笔生意，并逼着官方补上一条新规矩 |
| 情绪链 | 结构性缺口被点名（粮荒、矿石紧缺、工业承压）→ 「没人敢走的路才值钱」的赌博感 → 两边各自报价、互不信任的僵持 → 第三方见证下的成交快感 → 市场用最直白的方式反馈（船队堵港、价格翻倍）→ 官方被迫补规则、民间先斩后奏 → 五年后落点带来的时代感与隐忧 |
| 戏剧单元 | ①一方出现可命名的结构性缺口；②先行者押上全部身家（连船带货、借款入货）；③官方规矩成为实际阻碍（章程里没有这一项、货币不流通、护航只到某处）；④双方报出完全不同的价格体系，谁都不肯先交货；⑤引入第三方（驻军、军官、公会）做临时见证，把交易落地；⑥市场反馈超出预期，逼出制度定性（自贸区、多国共管、备案先例）；⑦制度落地后立刻切入权力摩擦与长期分离的个人落点 |
| 可替换项 | 商品→任意两类互补资源（粮／矿、药／钢、能源／人力、技术／原料）；商人→任意敢押上全船的小人物；货币不通→任意支付手段缺口（铸币／纸券／票据／以物易物／信誉）；见证方→任意能提供最低限度担保的权威（驻军、公会、使馆、教会）；制度落点→任意新机构（自贸区、共管区、特区、通商口岸）；时间跳跃的落点→任意一对普通人（登机口、码头、医院、工地） |
| 不可照搬 | 原书专名与具体设定：加文、王富城、王伟、陈平、吴老板、陈舟、奥姆卡、黑牙、艾德尔、索科洛夫、伊格纳托夫；沙勒曼岛、赤水港、奥伦港、格瑞赛斯、矮人王国铁炉堡、黑油城、诺尔丁城、瓦莱克西亚、哈巴罗夫斯克、坎萨城；金弗／金弗洛林、尼尔、魔晶、燃素、文明点；具体事件顺序：先私下试水→再堵港→再定性为自贸区；标志性台词与命名：「没人敢走的路才值钱」「港口临时货物中转备案」「那就补先例」「劳务派遣」 |
| 关键触发物 | 一叠印着王室徽记的纸券或一袋金币；一份写着「本岛章程无此项」的旧章程；一位愿意先交货或先付款的先行者；一份没有先例的临时备案文件；一道随时可能改变规矩的政令（查封、整饬令、限三日缴款） |
| 必要铺垫 | 必须让读者先算清两界的购买力差（一界的一袋粮等于另一界的几个月工资），否则差价不成立；必须让「官方的规矩」在前文成为可感知的障碍，读者才会为「先斩后奏」叫好；先行者必须先在小事上显出他敢赌的性格，否则押上全船像冲动 |
| 成立条件 | 双方必须各有一件对方真正急需的东西，且官方规则明显滞后于民间活动；第一笔交易必须由小人物先斩后奏办成、官方随后才补规则——顺序颠倒，爽感会变成行政审批；差价必须由**具体数字**支撑（多少吨换多少吨、几倍价钱、几天内船队堵港） |
| 复现步骤 | 1. 让一方出现可命名的结构性缺口，并把缺口换算成普通人能感受到的价格；2. 让先行者用一句「没人敢走的路才值钱」押上全部身家；3. 让官方规矩在交易前成为实际阻碍，并写明它为什么管不了这件事；4. 让两边各自报价、互不信任，把僵持写成具体的讨价还价动作；5. 引入第三方作最低限度的见证，把交易落地；6. 让市场用最直白的方式反馈（船队堵港、验货翻倍、价格拐点），逼出制度定性；7. 制度落地后立刻切到一对普通人的长期分离或一次权力摩擦，把时代感与隐忧一起给 |
| 失效情形 | 交易当天成交、全程无阻力，读者不会记住任何一次谈判；五年后的变化只用概述、不落到具体的人身上，时间跳跃就变成空洞的年表；官方补规则的段落写成行政流程说明，会让整条线的快感归零 |
| 反例/边界 | 不要把这个模式写成「现代工业碾压」——它真正的快感来自「账能算清」而不是「枪能打赢」，本书这一段几乎没有战斗；也不要把加文、王富城写成毫无私心的公家人，他们必须先算自己的账，官方才有资格在后面补规则；边界在于差价必须能被读者心算，一旦需要作者解释才懂，这条线就失效 |
| 关联节奏 | 节奏.md AX-408（第 211-216 章，事件 4/5、情绪 3/5、篇幅 3/3）、AX-409（第 217-219 章，事件 4→2/5、情绪 3/5、篇幅 3/3）、AX-517（第 290-291 章，事件 3→4/5、情绪 3/5、篇幅 3/3）、AX-629（第 359 章，事件 3/5、情绪 2/5、篇幅 3/3）；爽点循环 SL-402、SL-502、SL-610；情绪触动点 TP-406、TP-611 |

### EM-003 战后条约清算与内部政治分赃

| 字段 | 内容 |
|------|------|
| 读者想看什么 | 想看账本怎么算：一场大胜之后，成果如何逐条兑换成赔款、领土与人口；想看没上过战场的人在谈判桌上争抢红利；也想看胜利者因为太克制而反被对手抢走主动权的那一下错愕 |
| 情绪链 | 战争终结的释放感 → 全盘接受条件的错愕 → 条款逐条兑现的清算感 → 内部争抢红利时的摩擦与冷意 → 「账没算完」的不安 → 制度工具被反复使用、矛盾被挂账到下一阶段 → 新一轮扩张的引信被点燃 |
| 戏剧单元 | ①胜利方带着多套施压预案坐上谈判桌；②对手因最高层一句命令当场逐条应下全部条件，胜利方的预案全部落空；③条约锁定可计算的赔款年限与领土安排；④内部各方按贡献与位置争抢红利，摩擦公开化；⑤用一件具体工具（贷款、驻军、采购许可、人口交换）把矛盾暂时压住；⑥把战败国的重建速度摆到桌面上，重新评估危险性；⑦末尾埋下下一轮扩张的方向 |
| 可替换项 | 战争形态→任意阵营对撞；条约内容→任意可计量的赔款／领土／人口／市场条款；赔款形式→现金／资源抵付／劳务／人口交换；内部争抢的焦点→主权、市场准入、驻军权、矿产、选票；挂账手段→「不进入表决」「补先例」「下次再议」；新威胁的呈现→重建速度、未被触动的底牌、新领导层 |
| 不可照搬 | 原书专名与具体设定：林远征、李书海、孙文成、徐建国、赵文、索科洛夫、伊格纳托夫、艾德尔、温布顿、初代种、安塔尔、莉莉丝、艾雅；《沙勒曼岛合约》、瓦莱克西亚、赤水港非军事化、血渊服役、奥尔特尔群岛、坎萨城、克伦瓦亚、施瓦本镇；赔款「每年六十亿金镑分五十年」、十二万战俘换南方农业人口、三人换一人的「劳务派遣」；具体事件顺序：先当场全盘接受→再拆解南方→再内部争抢；标志性台词：「尽可能满足泛亚的一切要求」「陛下会理解的」 |
| 关键触发物 | 一张逐条宣读的条款清单；一份对手准备不足的全盘让步；一张被拆解的战败国地图；一个用数字表述的重建速度（几个月立起骨架、失业率下降）；一条被刻意搁置的争议 |
| 必要铺垫 | 战败方的最高决策者必须在前文出现过，且他的一句认输指令要能解释「为什么全盘接受」，否则谈判会显得太顺；内部摩擦的各方必须在战前就埋过（谁出了兵、谁只出了钱、谁一直骑墙），分赃段才有张力；条约的每一条都要能换算成具体的人或物 |
| 成立条件 | 必须存在一个跨阵营的长期制度性接触（同盟、理事会、联合指挥部），否则条约没有签署主体；胜利方内部必须有一处无法单方面解决的矛盾，否则分赃段写不出来；赔款与领土安排必须可计量，读者要能心算 |
| 复现步骤 | 1. 让胜利方带着多套施压预案上场，把「准备充分」写实；2. 让对手在第一轮就全盘接受，把胜利方的节奏打乱；3. 逐条宣读并兑现条款，每条都落到具体的钱、地或人；4. 让内部各方开始争抢红利，把摩擦写成公开的对话；5. 用「不进入表决」或「补先例」把矛盾挂账到下一阶段；6. 把战败国的重建速度摆到桌面上，制造新的危险性评估；7. 末尾埋下下一轮扩张的引信 |
| 失效情形 | 谈判太顺、没有一次拉扯，清算感会变成流水账；只报数字不写具体的人（谁被换走、谁被征税、谁的房子塌进灰里），条约段就没有情绪；战败国的重建速度如果写不出说服力，后续「危险性提高一档」就立不住 |
| 反例/边界 | 不要照搬「战胜国必然狮子大开口」——本书的胜利者反而因克制而被动，这个反直觉才是该模式的边界价值；也不要把内部摩擦写成反派或愚蠢，本书把亚美的主权诉求处理成「未进入表决」，矛盾挂账而非解决，这是群像内部政治的正常形态 |

### EM-004 代理人扶持与遥控感
