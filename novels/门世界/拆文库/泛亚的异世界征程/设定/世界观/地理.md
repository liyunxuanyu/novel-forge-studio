# 地理：泛亚的异世界征程

类型：平行世界／异世界碰撞

---

## 一、总体分布

全书的地理由**两大块被切开的大陆＋若干过渡区**构成：

| 区域 | 归属 | 说明 |
|------|------|------|
| 泛亚本土 | 穿越过来的那片大陆 | 华国、北陆联邦、露西亚（西伯利亚）、天竺次大陆、修卡马特、亚美所在区域等 |
| 维洛斯大陆 | 异世界原有大陆 | 伊瑟兰德帝国、格瑞赛斯王国、山地矮人王国、阿尔萨半岛联盟、精灵王庭、大荒原、沙勒曼岛、灰烬海等 |
| 中央大洋 | 两界之间的海 | 罡风层封死海面通道；泛亚一侧称「南荒海域」，维洛斯一侧称「维洛斯海」「中部海域」 |
| 极东大陆 | 罡风层另一侧 | 成片人工灯火、成熟文明、灵界天庭 |
| 星球尺度 | 全书舞台 | 等效直径达地球的**四点七倍** |

关键地理事实：

- 泛亚本土与维洛斯之间隔着**中央大洋罡风层**，该层**四五百年前一夜成型并隔断两块大陆**。
- 泛亚一侧把对面大陆称为**南荒海域之外的新大陆**；维洛斯一侧最初把泛亚当成「不见于任何海图」的蛮夷之地。
- 维洛斯的**东边罡风带是禁区**。
- 穿越后卫星发射接连失败，泛亚**只能靠船画地图**，直到第96章「新卫星的突破」、第204章天星二号入轨，才真正取得全域遥感能力。

## 二、维洛斯大陆

### 1. 伊瑟兰德帝国

血族帝国，全书最大对手。首都为**瓦莱克西亚**（原文亦出现「瓦尔克西亚」这一写法，多用于指血族首都远郊传送门一带，两处是否同城**原文未明确**）。帝国血族与皇室血脉是国本，国土法术集群与十三件圣器是国家级底牌。

| 地点 | 说明 |
|------|------|
| 瓦莱克西亚 | 帝都。皇宫地下有圣堂深井与十三件圣器；皇宫底下是综合人口管理系统的终端；议政大殿与议会大厅在此 |
| 瓦莱克西亚远郊传送门 | 血族首都远郊平原清空居民、建成黑曜石传送门，11万先遣军在此集结；「瓦尔克西亚」这一写法即用于此处 |
| 赤水港 | 南方核心港口。第73章六港同遭轰炸、通天塔倒塌、码头区报废，直接损失二十亿镑；第77-85章被封锁轰炸一个月后魔能断绝、外城无政府，黑潮同化外城区，最终在核爆中化为弹坑；战后划为**非军事区** |
| 奥克塔维尔 | 帝国西部作战后方基地。第258章城防广域护盾大阵眼开裂碎裂，整座基地被摧毁 |
| 塞恩塞蒂亚 | 铁路枢纽。第259章被废，帝国南北交通调度断掉 |
| 弗拉迪克萨、喀莫瑞安、赫墨瓦恩 | 第一波次打击目标城市；赫墨瓦恩的世袭老宅塌进灰里 |
| 圣格力高城 | 格力高家族祖地 |
| 威尔卡城 | 格力高公国城市，被帝国第十五军团第四师第二团攻破 |
| 特维尔港 | 帝国核心港口，林晓在此被全境通缉 |
| 亚苏尔自由市 | 不归公国管辖，公国通缉令不自动生效，泛亚帝国方向负责人李瑞的据点 |
| 血渊 | 禁军至高统帅宣判主战派战后前往服役之地 |

帝国南方被拆解为**七八个国家**，北方为皇室直辖地等**九处核心领土**。

### 2. 格瑞赛斯王国

| 地点 | 说明 |

| 克鲁威尔峡口／克鲁威尔要塞 | 西线命脉。峡口正面留守兵力曾只剩原有规模三分之一，要塞兵力一度推至12万 |
| 萨南沙 | 第271-282章围城战发生地，升起城市级护盾，城头猩红光束击落两架米格-21 |
| 奥伦港 | 与泛亚使团首次交锋的港口，巡防舰拦截、马克西米利安索要贡品礼单；也是加文放粮压价之地 |
| 奥尔梅克特 | 火车站，第290章粮矿互换与长期供货协议在此签下 |

| 阿尔萨半岛联盟／坎萨城 | 半岛联盟，坎萨城礼宾总管塞巴斯蒂安出面赎回艾萨克斯 |

### 3. 山地矮人王国

城邦联盟，**至高王无权强制各城邦履约**。

- **铁炉堡**：核心据点。第61章签下**三千多万吨铁矿石合同**，报价降一成；第291章因矿价问题停掉三条生产线。
- 第353章华国外交部李书海与矮人王国首席贸易使节**艾姆罗**签下**十年内全部矿产只对华国开放官方出口渠道的独家协议**。

### 4. 瑟兰迪尔学院

建在**灵界与现实之间的以太层**，由初代院长开辟，以绝对中立为根基，靠中央魔能塔抽取以太层能量，**规模可比华国浙江省**。院内分历史院等机构，学员来自阿尔萨城邦联盟、伊瑟兰德帝国等各方。学院资料中藏有近一千年前极东大陆技术体系的记录。

### 6. 沙勒曼岛

由海盗窝与纯军事驻屯点，演变为泛亚的跨海前进基地与行政实体。

- 第13-19章：泛亚使团在此清剿据点、救出艾莉希娅与普莉菲儿。
- 第211-221章：王富城的「远航号」在此入港，护航任务终止；港务局与驻军折中出「**港口临时货物中转备案**」；北京拍定沙勒曼岛全境划为**自由贸易区**、升格**泛亚直辖特区**、实行**多国共管**。
- 五年后分为**北港、东湾、西港**三个市辖区，接上旅游与直飞航线；基地已清剿周边**百海里**海盗据点。
- 升格后成为伊瑟兰德南方工业集团眼中的第一打击目标，直接接上黑牙受雇袭击「永兴号」。
- 战后**沙勒曼岛北港市**海滨会议中心成为泛亚与帝国的和谈地点。

## 三、天竺次大陆

属泛亚本土，穿越后因电磁脉冲崩解、政府失去控制，核武去向不明，由华国推动维和与安全走廊、数月后全面停火。

| 地点 | 说明 |
|------|------|
| 达罗毗荼联邦 | 天竺南部国家。第122章伤亡定格**一百一十六万**，总统被迫下台，安德拉邦南部土地经辐射探测确认可保留 |
| 安德拉港 | 第116章神降仪式后**不到一个时辰彻底沦陷**；第121章神子把此地重构成神殿之城，随即被两枚百万吨级核弹抹去，化为焦坑 |
| 萨普塔吉里 | 沦陷县城，泛亚联合军在此抢筑纵深筑垒，集结**四十余万大军与近十万预备队**，惩戒舰队完成环形封锁；2036年4月1日凌晨六点全线齐射 |
| 达利特村落 | 神降仪式开始之地 |
| 帕尔瓦自由市 | 城东贫民窟是梦魇教会残部与投机者的据点 |
| 卡卡尔邦 | 主动捐出封存十余年的全部核废料 |
| 临海 | 泛亚联合总部所在地；泛亚与审判庭在此敲定常驻机构与联合执法框架 |
| 山南联邦／普拉县 | 被红色政权包围；艾克萨斯一行在此雇牧民次仁带路登圣山，谷地电磁干扰消失、魔力浓度上升且纯净 |
| 乃堆拉边防哨所 | 巡逻班在雪堆里救起艾克萨斯四人 |

## 七、极东大陆与罡风层

- **极东大陆**位于中央大洋罡风层另一侧。第206章微光夜视下可见**成片人工灯火**，赵明远排除噪点复核后确认对岸存在成熟文明，并禁止向外发试探信号。
- **极东灵界**是人工封禁的独立维度空腔，内部是**被规整穹顶罩住的闭合环形巨城**，全域遍布**高维级攻击打出的玻璃化熔断口**；塔尖暗红烈阳跳动，一道意志发出「何人胆敢，窥视天庭」的警告。
- 极东大陆近一千年前已出现与泛亚技术体系相像的器物，那边的人自称**修士**，境界分**筑基／金丹／元婴**；当地约八百年前出现过线膛燧发米涅枪的第一代原版。
- 天庭处于**封印加固与备战状态**，阳帝把威胁归因于罡风之外与高天之上；卦道真仙三次推演因果都卡在同一节点，判明因果线被从源头遮断。
- 第357章，帝国一侧的安塔尔把对外方向定在**极东**。

## 八、中央大洋与外围海域

- **中央大洋罡风层**：四五百年前一夜成型，封死两块大陆之间的海面通道，同时阻断肉桂等商品的供应。
- **新南印洋**：共识号测绘海域，第5章在此雷达抓到十二海里外的不明移动目标，完成两个世界的第一次接触。
- **中部海域**：海盗活动核心区，六个海盗王割据；帝国海军向此海域海盗发私掠证、提供退役军舰并默许港口补给。
- **南荒海域**：魔力稀薄、被称为不毛之地；帝国血族飞艇舰队曾在此与泛亚舰队接战。
- **维洛斯海**：第262-270章帝国北方第2分舰队在此被全灭。
- **灰烬海**：见维洛斯大陆节。
