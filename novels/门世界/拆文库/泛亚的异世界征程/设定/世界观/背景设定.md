# 背景设定：泛亚的异世界征程

类型：平行世界／异世界碰撞

---

## 一、核心规则：集体穿越

### 1. 事件本身

全书的地基是一次**集体穿越**：泛亚经济合作同盟（PAEC）所在的整片大陆，连同城市、人口、工业体系与军队，被整体置换到另一个宇宙。

- 异变发生时，跨境通讯同时中断。粤西水产加工厂工人陈舟把手机刷不出内容当成基站故障；叶捷琳娜堡卡车司机克洛夫斯基推开窗，看见**乌拉尔山脉消失、原地是一片无边大海**。
- 华国西北卫星监测中心三个台站交叉确认：**三颗未知球体同时出现在近地轨道外侧**，此后一直沿稳定轨道绕行。
- 卫星全灭，卫星消失伴随的**电磁脉冲**打穿薄弱地区的基础设施；天竺政府因此失去控制、国家崩解，**核武器去向不明**。
- 北陆联邦东部被海洋从地图上切下、首都失联，十个州与自治区首脑在哈巴城表决授权特鲁特夫统筹军政资源。

### 2. 「不在原先那个宇宙」

灾后一个月通讯部分重连，各方首席科学家对完信息后，由一位年长的斯拉夫科学家给出结论：**「我们连同一整片大陆，已经不在原先那个宇宙了。」**

支撑这一结论的硬证据：

| 证据 | 内容 |
|------|------|
| 星空无参照 | 北极星找不到了，猎户座、大熊座、仙后座一个都拼不出来 |
| 星图比对失败 | 第210章天星二号以高精度光学成像做天文望远，星图比对**全部模板匹配失败**——这不是原先的银河系 |
| 外网不存在 | 外网彻底消失，没有任何外部参照 |
| 射电手段失效 | 外层空间的魔力洪流把射电天文定位手段彻底废掉 |
| 行星尺度 | 第206章曲率测算得出，这颗行星**等效直径达到地球的四点七倍** |

**原文未明确**异变的成因、实施者与被切走那片陆地的去向。天竺核武的下落对书中所有角色都是空白。

### 3. 时间轴锚点

- 灾后至2024年底：PAEC成立、大重铸展开，粮食产量恢复到灾前95%、工业用电回升至80%。
- 2036年4月1日：天竺萨普塔吉里全线炮击，事件后被定性为「311事件」。
- 2043年7月18日凌晨4时：华国从西部「无常」基地发射八十六枚千万吨级导弹打击帝国本土。
- 2043年8月：泛亚与伊瑟兰德和谈条约正式签订。
- 2045年12月17日：维洛斯诸国使节团船队驶入上海外滩。
- 2046年1月：上海，泛亚发展理事会战后首次全体会议。

## 二、两个世界的并存与隔绝

两个世界**并存但基本隔绝**，隔绝的主要手段是地理。

- **中央大洋罡风层**：泛亚本土与维洛斯大陆之间隔着一道罡风层，**四五百年前一夜成型并隔断两块大陆**，封死了海面通道。维洛斯的肉桂因罡风层断供。
- **极东大陆**同样在罡风层另一侧，被罡风层阻断数百年。
- 隔绝并非绝对。维洛斯一侧掌握**传送门**（血族首都瓦尔克西亚远郊的黑曜石传送门），格瑞赛斯在帝国腹地埋有**隐秘空间节点信标**；泛亚一侧则靠**空间水晶、天然以太层裂口、锚点系统与天降轨道传送**打通通路。
- 第357章，帝国一侧的安塔尔在温布顿宅邸提出动用「开国手段」，把对外方向定在**极东**。

## 三、泛亚联合体（PAEC）

### 1. 成立

灾后一个月，天竺崩解、核武去向不明。华国代表第一个开口，推动天竺维和与安全走廊，机队飞抵新德里建立安全走廊，数月后全面停火；随后**泛亚经济合作同盟（PAEC）成立**，创始成员国名单落地，「大重铸」展开。

华国成为秩序主导方，北陆联邦东部出现临时权力核心（哈巴城授权特鲁特夫）。

### 2. 运作机制

| 机构／机制 | 内容 |
|-----------|------|
| 泛亚理事会 | 全体会议制，强调协商一致；第16届大会上越南代表当众质问华国 |
| 泛亚联合总部 | 设在临海；理事长向全境直播发布四十八小时最后通牒 |
| 泛亚发展理事会 | 战后负责分配利益与话语权，亚美要求承认其对奥尔特尔群岛的主权被拖延 |
| 联合情报中心 | 第109章立项，建在临海，负责跨国情报与代理人方案 |
| 泛亚联合防卫协定 | 第37-60章签署，华国承担先期防御任务 |
| 联合舰队／联合指挥部 | 三百艘舰艇规模的惩戒舰队；指挥部深夜开加密视频会议 |
| 沙勒曼岛直辖特区 | 全境划为自由贸易区、升格泛亚直辖特区、实行多国共管 |

### 3. 内部张力

- 亚美由附庸向真正国家进化，第351章公开要求承认奥尔特尔群岛主权。
- 露西亚坚持维持能源与铁路原价；中亚五国与蒙古国出兵后要求重新分配利益。
- 东南亚各国（越南等）要求重谈关税减让与产业分工协议；南朝鲜与和津是幕后鼓动者。
- 华国以油田减产、航运改道、检验检疫加严、基建贷款重评、技术转让暂停、签证与交换生收紧**六项措施同时出手**，不宣布任何制裁即打瘫东南亚六条线。
- 维洛斯资源涌入使各国可绕开华国直接交易，经互会式体系撑不下去。

## 四、魔力与工业技术的关系

这是全书最核心的一条技术规则：**两种技术体系互相干扰、互相不可替代**。

### 1. 双向干扰

- **魔力浓度与电磁波存在双向干扰效应**：泛亚舰队的电磁波就是特拉法尔追踪十一年的「魔力紊乱源头」。
- **高轨道魔力浓度至少是本地常态三百倍**；近地轨道实测**一百五十流尔**，被符文组拉平波形后才允许卫星入轨。
- **广域电磁干扰可以让中低阶法师的魔法与所有魔导装置同时失效**：黑牙的魔导炮、巫祭与流浪法师、水下蛙人都被一次归零，法师识海受创。
- **干扰之力并非专门针对魔力而是频率压制，可用更强的魔力强行驱散**：薇薇安索要八十吨魔晶、激发皇室血脉化为成熟形态，用高于干扰频率的魔力推开电磁脉冲，但泛亚地下锚点阵列发射单元随之过载烧毁。
- 帝国各势力**没有系统电磁干扰手段**，帝国至今未意识到魔力可影响电磁信号。

### 2. 工业装备的两条根

- 泛亚方向：先锋-1型外骨骼（续航48小时、伺服延迟0.03秒）、K1型三十五毫米突击步枪、先锋A2动力装甲（源于穿越后相变的固态电解质样品，能量密度7200瓦时每千克）、A30超级巨嘴鸟（原型为旧地球A-29巨嘴鸟与农用AT-802空中拖拉机）。
- 帝国方向：帝国研究院因枪钢与符文补强不过关，**放弃仿制缴获的AK-12**，改以魔晶粉末与铜合金弹壳造出**伯格利A型连发魔导枪**（每分钟五百发、极限稳定距离约三百米），并推出「魔眼」与「爆炸飞虫」——两者均由泛亚战场残骸逆向研究而来。

### 3. 能源侧的新变量

黑油城火焰地狱谷的裂解塔**意外分离出液态魔力元素**，使「燃素」实现量产，日产量1600万桶的工业园区直接或间接养活周边近百万人。

## 六、国土法术集群与圣冠

- **国土法术集群**由**五千七百八十六座通天聚能塔**构成，是帝国的国家级防御底牌。但**只有皇帝亲自主持才能全效运转**，此前效能不足一成。
- **圣冠**是把**活人灵魂临时改造成超量信息容器**的转换装置。第285章温布顿亲手取冠，为戈尔菲亚家小儿子**尤里安·冯·戈尔菲亚**加冕，尤里安惨叫挣扎、瞳孔褪成浅灰，脑中响起「全知者运算系统」的接入提示；随后被打开辅助端口改造成运算核心，通天塔群魔力朝帝都倒流，**集群效能升到三成五**，代价是尤里安七窍渗血、脑组织持续受损与全境限量供能。
- **皇宫地下圣堂深井上共十三件圣器**，并有沉睡的神之子嗣，沉睡者已沉寂**一百多年**。其中**圣枪能启动超古代武器系统**，被皇帝动用过一次后亲手封印。
- 第315章尤里安强抽五千七百八十六座通天聚能塔魔能构筑国土法阵，拦下三十七枚导弹、漏网四十三枚，二十余座工业城市化为废墟，直接死亡一百二十万到两百五十万，工业总产值倒退四十年。
- **通天塔每天半数魔能去向不明**，账面上查不到；魔能网络图把那几条线路标成朝帝国腹地最深处汇聚的虚线。

## 七、通天塔与魔力节点

- **通天塔即高效聚魔塔**；三百年建塔已使全大陆魔力浓度下降。
- 赤水港的通天塔在轰炸中倒塌，使该港的魔力供给体系失效。
- 通天塔地底存在**天然魔力焦点**，可用于封印（伊洛恩曾决定借此地底焦点强行封印黑潮，代价是细胞老化）。
- **通天塔供能可把超凡者的全力厮杀窗口从七八分钟拉长到十几分钟**；维洛斯十环禁咒需传奇强者为核心、完整战斗法师团与**一两座通天塔供能一天以上**才能发动。
- 帝国核心生产藏在山区与**魔力节点**附近，因此不在导弹最佳落点上。

## 八、神性与邪神

### 1. 神性

- 神性是**可分割、可立约、可被血光烧毁**的东西。薇薇安割掌以血激活石壁光膜，掌心的**灵界契约烙印被父皇血光烧毁**；她又以**血神瑟伦诺尔后裔**之名向灵界全体起誓，分出部分血神神性，引来无数存在厮杀争夺，一道深蓝光影与她立约并留下羽毛状印记。
- 神性化有明确代价：薇薇安体内**禁咒反噬与神性化双重伤害**长期未愈。

### 2. 邪神

| 名称 | 说明 |
|------|------|
| 终末之神（破灭邪神） | 教义为「万物终亡」，靠施食布道同化人心，以百万人的怨气为神降燃料；赤水港外城被其黑潮同化 |
| 恶魔大君永寂 | 实为叛出审判庭的审判官**恩卡洛斯**，沉睡百年，被牧首以两名信徒残躯为门引来，屠灭十五名魔导骑士，最终被十万吨当量核航弹汽化 |
| 梦魇之主 | 原为梦之教会噩梦一系的普通主教，撕裂梦之河、窃取噩梦权柄登神；在安德拉港/天竺方向降下紫色雾潮 |
| 欺诈魔君纳赫特玛 | 第341-342章由薇薇安献祭蜕变而成，气息接近近神，最终被四枚东风-15云爆弹头清除 |
| 神子艾赛罗斯 | 由女教长以恶魔大君之躯崩解产下，自称诸神代言人，把安德拉港重构成神殿之城，被两枚百万吨级核弹抹去 |

### 3. 邪神污染与三个组织

- **邪神污染**：炮击过的土地残留污染，步兵一松懈就被污染钻脑异化；梦魇从沉睡者额头裂缝爬出、靠被吸干梦境的活人增殖。
- **梦魇教会**：六大教团之一。第88章六大教团其余五支首脑密议，隐秘教派牧首宣布神启——**应许之地名为天竺**。第123章梦魇教会高层决定把精英力量从维洛斯转移至天竺、再召唤一位神子。
- **永眠者**：末代教皇**阿维克利特**，原是中部一个比伊瑟兰德帝国更古老的覆灭王国王子，六百年前亲手策划灰烬海神降仪式。他看穿「神赐升华」是把飞升者灵魂碾碎、以亡魂残渣填入空白容器造出服从神意的傀儡，由此认定梦魇之主是邪神，率残党举起反旗。
- 神子的定义：**灵界邪神在现世的力量锚点，不受现世法则排斥**，六尊古神一同赐福并立其为凡世唯一代言者。黑精灵帝国「疯皇」莫斯塔尔曾献祭帝都一百二十万人口孕育腐败神子。

## 九、辐射对邪神污染的克制

这是全书最重要的一条「非魔力体系」规则：

1. **赤水港核爆后，本应存在的辐射完全没有被检测到**。张代表推测邪神污染与核武器存在未知相互作用。
2. 第114章在大亚湾核电站现场验证：乏燃料样品与邪神污染样本接触后，辐射侵蚀封印符文、污染外泄后被吞噬消散，**辐射值从二十万伦琴降到十万**。双方以**三百吨黄金、一百六十万颗魔晶**与超凡者训练条款成交，乏燃料折价**两公斤黄金一公斤**。
3. 第119-120章：**乏燃料微尘**撒进雾潮控制的十五座县城，梦魇躯体褪色崩解、紫雾大面积塌陷。但核心神域靠灵界裂隙神力**兜底再生逆转**，消融速度回落。
4. 第152-156章：**核辐射不属于魔力体系、不遵循灵界法则、不受神明权柄约束**。永眠者以即将消散的灵魂躯壳包裹脏弹残余核辐射，穿过神力阻隔**撞断梦魇命途长河**，梦魇之主神格崩解、露出干枯老人本体，被现身的血皇以血色火焰焚尽。
5. **贫铀弹对邪神造物形成天然克制**：贫铀弹芯狙击弹两枪打穿已升魔教徒的神力护罩，辐射读数始终在安全区间。
6. 核废料由此从战术底牌变成可量产出口商品：审判庭当天追加订单且数量翻了好几倍，精灵王庭与中小势力纷纷下单，露西亚启动专用反应堆批量生产人造核废料。

## 十、天庭与极东的封印

- 第206-208章：天星二号在暗面边缘发现**极东大陆铺开成片人工灯火**，确认对岸存在成熟文明。
- 极东**灵界是人工封禁的独立维度空腔**，内部是**被规整穹顶罩住的闭合环形巨城**，全域遍布**高维级攻击打出的玻璃化熔断口**。
- 塔尖暗红烈阳跳动，一道意志发出警告：**「何人胆敢，窥视天庭」**。整套灵界探测符文阵列核心刻线被反向灌入的信号烧毁。
- 天庭一侧：**卦道真仙三次推演因果都卡在同一节点**，判明因果线被人从源头遮断，源头在罡风之外；**阳帝决定加强天庭封印**，另一名帝者提出趁「逆种」沉寂十多年后加固防御、一并准备。
- 天庭内部有人想起几百年前从罡风对面过来、把天庭折腾得鸡飞狗跳的那个男人。
- 前代穿越者线索：瑟兰迪尔学院历史院资料与东区文物仓库确认，**近一千年前极东大陆已出现与泛亚技术体系相像的东西**，那边的人自称修士、境界分筑基／金丹／元婴；一把**约八百年前的线膛燧发米涅枪**被确认是第一代原版，此前没有任何相似物，当年即引爆军事革命、打破超凡者垄断战场并衍生出魔弹射手职业。林晓由此判定存在前代地球穿越者。

## 十一、其他特殊设定

- **瑟兰迪尔学院**建在**灵界与现实之间的以太层**，由初代院长开辟，以绝对中立为根基，靠中央魔能塔抽取以太层能量，规模可比华国浙江省。
- **公民身份证刻印血脉法术**；帝国**综合人口管理系统依托全境魔力塔**，以瓦莱克西亚皇宫底下为终端，加大输出可看出公民情绪。
- **传说禁卫军并非真正生灵，而是皇帝亲手创造的神之侍卫**。
- **存续之塔**：第121章血族皇帝从二十年沉眠中苏醒，下令启动存续之塔。
- **血渊**：禁军至高统帅宣判全体主战派战后前往血渊服役。
- **初代种**：白发银发赤瞳的新人，大批接替被处罚的主战派议员席位，受议长温布顿强制庇护；泛亚情报部门两种来源推测都被否决。
- **伊瑟兰德帝国皇帝五年未发一言，王座大厅漆黑无灯**；帝国议长温布顿主政。
