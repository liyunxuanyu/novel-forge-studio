# 本宇宙华国

- 类型：国家

## 核心人物

- `角色/方景.md`：穿越者，机器唯一的往来通道，第1章在军方审讯室睁眼，第70章由陆军学员升为大校，是237计划指定的探索前锋。
- `角色/朱进程.md`：第3章乘直升机赶到豫省，当场拍板并命名237计划；第11章批下1000亿。
- `角色/朱老.md`：本宇宙华国高层元勋，第25章掏出设定集点破电影人物身份，此后长期是237计划在最高层的决策者与定调人。他与朱进程是否同指，本书未给出一致证据，两人在本档案中并列。
- `角色/陈立民.md`：237计划保密体系与反谍行动负责人，第2章当面找到方景交底，第15章起任安全局负责人，后期兼管对异文明俘虏的审讯。
- `角色/赵光耀.md`：西山基地对接负责人，第4章接手对接方景，长期担任237计划对外任务的上传下达与后勤协调人。
- `角色/周元.md`：西山基地237计划队员，第4章作为五名队员之一登场，方景的教官、陪练、贴身护卫与行动组带队人。
- `角色/袁宏.md`：本宇宙太空军舰队指挥官，最初任武夷山舰舰长，后成为远征舰队旗舰指挥官。
- `角色/庞海.md`：本宇宙舰队指挥官，第291章指挥第一次太空飞船战争，长期带舰队执行高风险任务。
- `角色/吴统.md`：华国海军舰长，曾任南疆号、昆明护卫舰舰长，后升任本宇宙太空舰队旗舰舰长。
- `角色/董教授.md`：本宇宙科研专家，第706章首次出场，专家组的核心判断者之一。
- `角色/荷洛斯.md`：工程师族活体成员，第179章被抽血取样，第184章交出飞船操控方法，后成为本宇宙首席科学家之一。
- `角色/天火.md`：赛博坦古老霸天虎，第349章同意加入237计划，专精火种源改造与能量装置。
- `角色/天灵.md`：本宇宙基地一方的智慧体，根须与植物覆盖基地内外，负责全图监控、截获通讯与情报通报。
- `角色/卡卡.md`：米亚文明领航员，第989章成为237计划新成员。

## 立场倾向

对主角一方即本方。方景在第2章主动交底后由被审者转为编制内的唯一通道，国家由此成为全书真正被抬升的主体。对米国、五眼联盟与立本，开局是隐性对抗中的先手斩断，第43章起转为正面撕破脸，第58至64章在西太平洋战争中打成战胜国。对后来的异文明，本宇宙华国的立场按对方是否可交流分层：能谈的收作盟友或附属，不能谈的直接抹去。其对外姿态随技术存量升级而变，第506章前后已由「各国并列的一方」转为人类整体的代表者与邀请方。

## 与其他势力的关系

- 本宇宙华国 → 米国、五眼联盟、立本：由隐性对抗到公开碾压（第3章，因为237计划立项与保密要求，对手在华情报网络集体断联）。
- 本宇宙华国 → 米国：由隐性技术竞争到公开战略宣示（第12章，因为突然官宣载人登月，米国情报口失手）。
- 本宇宙华国 → 米国、立本、南棒：由司法讹诈与舆论战到两小时内全歼联合舰队（第43至64章，因为反倾销判决与环球矿业控股权之争）。
- 本宇宙华国 → 米国：由战场对手到逼其投降的一方（第791至805章，因为袁宏单舰与金属球碾过西海岸，米国总统什布尔签下降书）。
- 本宇宙华国 → 米亚文明：由陌生文明到受条件约束的准盟友（第880至933章，因为领航员主动通讯并交底，荷洛斯提出反向渗透疑虑）。
- 本宇宙华国 → 赖亚人：由陌生对峙到施压方与被迫配合方（第812至829章，因为袁宏舰队开进赖亚星大气层，以白鲨被俘与同归于尽相逼）。
- 本宇宙华国 → 霍尔文明：只有单向观察（第908至922章，因为霍尔星系被判定为星系巨炮，朱老下令静观其变、不跟风突破）。
- 本宇宙华国 → 亚空间核心：由长期敌对清缴到计谋制服与永久禁锢（第926至947章前后，因为专门研制的麻醉剂与上万刺锁偷袭）。

## 组织与实力

结构上以237计划为核心：第3章在燕京立项，保密级别绝密、保密年限永久不启用；第5章完成三部分编制，设西山基地、空间门基地与节点岛等设施，决策层为朱进程／朱老一级，执行层为陈立民、赵光耀、周元，科研层为荷洛斯、天火、董教授、天灵，军事层为袁宏、庞海、吴统。规模与技术水平按原文硬数据：第6章方景算出对面电池储电能力是本宇宙168倍，第3章明确本宇宙落后十几年、想要正面击败米国至少还要几十年；第11章批下1000亿；第13章由615厂承接十六台发动机，代号「风暴九号」；第401章歼灭舰已能一炮抹去恒星系；第476章出现十公里级歼灭舰；第651章铺开一千台行星防御基地；第812章远征旗舰为十公里级掠星舰；第912章前进基地母港上千艘飞船加装反物质宇宙隔膜；第1159章本宇宙与各平行宇宙负责人划定近一万六千光年疆土。第1240章237计划由地下隐名团队转为公开团队。
