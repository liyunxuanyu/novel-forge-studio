# 先驱族与骑师族

- 类型：文明

> 本档案按同一文件名收两类文明：**先驱族**（《环太平洋》世界的放牧者）与**骑师族**（即工程师一族，异形与普罗米修斯世界的银河霸主）。两者是彼此独立的文明，原文在第234章把「工程师」与「先驱族」并置为两方。

## 核心人物
**先驱族**
- 先驱族首领：第229章判定人类得到其他文明扶持，下令长老会准备强攻缺口；第232章把目标改为挖出人类背后的支持者。
- 赫尔落：先驱一族守卫虫洞的放牧执行者，第223章为报复与掩盖违规提前投放五只六级怪兽，第229章读取六级怪兽记忆后向首领上报人类科技大跨代，第234章被黑雾吞没死亡。
- 长老会与首领主脑：第229章首领下令长老会准备强攻；第234章首领主脑被荷洛斯提前劫持并读取，先驱族失去最高指挥。

**骑师族（工程师一族）**
- 迪诺：工程师一族的最高长老，原属主张毁灭一派的路线代表，被关押在始祖庙一带。第209章在异形世界与朱老谈判、滑跪接受合作条件，第210章放弃迪肯路线，第366至367章离开始祖庙破解叹息之墙，第383章用压缩包解释维度，第1240章以首席科学家身份随朱老出席发布会。
- 荷洛斯：第201章被九州抓获，其手册被人类舰队用于潜入天堂星；第234章由侦察判读转为执行族灭，第260章转为技术顾问参与拆解工程师飞船。
- 佩斯：第208章关押城池中穿囚服、披兜帽、持拐杖的长老，原文写作最高长老。
- 荷光与诺达斯：第208章被钓鱼局钓出的工程师，荷光体内有生物殖装、可连接创造者一脉。
- 诺伊：第590章探矿失败并报出守卫数量。

## 立场倾向
**先驱族**：对主角一方为敌。第229章由放牧改为强攻并追查人类背后的支持者，第230章放出上千只六级怪兽冲出缺口；第234至239章被九州与本宇宙族灭，寄生派灭绝、另两派撤离两个星系。
**骑师族**：对主角一方由敌对转为归降与合作。第201章天堂星聚居地被突袭，第209章迪诺滑跪接受合作条件，第210章随人类去《环太平洋》世界；第234章荷洛斯转为受限制的前锋协作者、参与族灭先驱族；第1240章迪诺以首席科学家身份公开露面。

## 与其他势力的关系
- 先驱族 → 地球生物圈：以怪兽蓝毒素作为培养基无差别改造环境，把改造本身变成生物坐标（第211至249章一段记述）。
- 先驱族 → 破碎穹顶与米国第一舰队：由放牧者转为强攻方（第230至231章，因为首领判定人类得到其他文明扶持，上千只六级怪兽冲出缺口，米国第一舰队被击溃）。
- 先驱族 → 九州与本宇宙：由交战到被族灭（第232章九州舰队苍白之光把三百头怪兽屠戮殆尽，第233章何帆舰队挥师东进，第235章近三千颗氢弹与反物质炸弹过门，第238章五颗超级人造太阳煮海，因为上级下了彻底灭绝先驱族的指令）。
- 荷洛斯 → 先驱族：由对手关系变为单方面清除（第234章，因为已判定对方为苟过大衰退的基因寄生体、视为愚蠢与自我阉割，动手毫无犹豫）。
- 何帆 → 先驱族（寄生派）：第238至239章下令煮海并执行彻底灭绝，连海底基因库与带遗传物质的生命体一并清除。
- 吴老 → 先驱族：第239章得知寄生派被屠灭后长久大笑，十一年怪兽战争积下的血海深仇得到清算。
- 何帆 → 先驱一族恒星系：由交战方转为单方面的资源接收（第228至249章一段记述中把舰船转为开矿船，探测队确认97颗行星全是备用资源星球）。
- 工程师一族 → 人类（朱老与九州）：由被突袭到技术换族群存续（第201章催眠气体放倒广场上的工程师，第206章清点出二十三万俘虏，第209章迪诺滑跪接受合作条件，第210章随人类去《环太平洋》世界，因为朱老抛出另一个宇宙存在掌握虫洞技术的生物文明这张牌）。
- 工程师一族 → 始祖迪肯与黑水：第210章迪诺彻底放弃迪肯路线，因为黑水就是迪肯的血液。
- 创造派与毁灭派 → 彼此：第210章工程师一族分出使用飞碟状飞船的创造派与使用C型飞船的毁灭派。
- 周元 → 工程师一族：由单纯驱使转为带条件的期许（第228至249章一段记述中承认其技术进展但不交付，因为对方技术本就超过人类）。
- 荷洛斯 → 人类一方：由俘虏转为受限制的前锋协作者（第201章被抓获，第234章带同族与人类作战人员核对作战计划）。
- 工程师一族 → 237计划：第1240章迪诺随朱老出席发布会。

## 关键事件
1. 第161至176章 普罗米修斯号科考团前往工程师遗迹，仿生人大卫录下工程师语言体系并建成翻译。
2. 第201章 三十三艘舰船借「召唤之音」短距跃迁压到天堂星，催眠气体把广场上欢呼凯旋的工程师成片放倒。
3. 第206章 天堂星清点出二十三万俘虏。
4. 第207章 异形世界一万名工程师科学家被全部打包带走。
5. 第208章 钓鱼局钓出荷光与诺达斯，全域监控与直播把次级长老的密谈变成抓捕名单。
6. 第209章 朱老点破监听并以新宇宙虫洞文明说服最高长老，迪诺滑跪接受合作条件。
7. 第210章 迪诺放弃迪肯路线答应合作，工程师一族随人类去《环太平洋》世界；同章交代工程师一族又称骑师族、曾在异形世界称霸，其依赖始祖迪肯繁衍的基因序列已无力繁衍演化，剩下的人分成创造派与毁灭派。
8. 第211至227章 十二台六代机甲以龟壳阵推进，方景贴脸轰杀拉诺斯与潘洛斯，第223章赫尔落投放五只六级怪兽，第226章拖着完整六级兽尸出海、虫洞信息收集完毕。
9. 第228章 方景归来昏厥，赵光耀清点二十艘战舰备战。
10. 第229章 赫尔落上报异常科技，先驱族首领下令长老会准备强攻缺口。
11. 第230章 上千只六级怪兽冲出缺口，破碎穹顶与米国第一舰队陷入绝望。
12. 第232章 九州舰队苍白之光把三百头怪兽屠戮殆尽。
13. 第233章 空间门开启，何帆率二十艘巨舰挥师东进正式开战。
14. 第234章 五艘载满黑水的工程师飞船冲入前哨基地，赫尔落被黑雾吞没死亡；荷洛斯提前劫持先驱族首领主脑并参与读取。
15. 第235章 近三千颗氢弹、金属氢炸弹与反物质炸弹过门。
16. 第237章 先驱星进入辐射冬天，何帆决定连炸三天并投黑水。
17. 第238章 五颗超级人造太阳被投进海洋煮海，除前哨基地外先驱族痕迹全无。
18. 第239章 寄生派灭绝、另两派撤离两个星系；吴老得知后长久大笑。
19. 第259章 先驱恒星系被定位为纯资源宇宙，开矿任务转交环太平洋东方大国。
20. 第260章 荷洛斯转为技术顾问参与拆解工程师飞船。
21. 第366至367章 迪诺离开始祖庙亲自下场，当场破解叹息之墙并把完整屏障模型传回研究室。
22. 第383章 迪诺用压缩包解释维度，感慨单一种族的思维局限。
23. 第1240章 迪诺随朱老出席发布会，以首席科学家身份公开露面。

## 组织与实力
**先驱族**：银河系昔日的「放牧者」层级文明，靠在太平洋底缺口投放怪兽改造地球环境（第211至249章一段记述）；掌握六级怪兽、磁力骨盾与生物电磁脉冲（第223至225章）；拥有生物计算机、长老会、首领与首领主脑的层级（第228至234章）；母星设有海底基因库与观察站（第238至239章）。第239章之后寄生派灭绝、另两派撤离两个星系；其恒星系内97颗行星全是备用资源星球（第228至249章一段记述）。原文未明确其人口规模与虫洞的具体参数。
**骑师族（工程师一族）**：曾是在异形世界称霸的银河系霸主文明（第210章），依赖始祖迪肯繁衍而下的基因序列已无力繁衍演化、进化无法回头（第210章），黑水即迪肯的血液（第210章）。其聚居地为天堂星，有船坞、飞船维修巢与生物殖装技术（第201章、第210章）；第206至207章一段被清点出二十三万俘虏与一万名核心科学家；第210章起在火星轨道拼装飞船。
原文未明确工程师一族的自称、族群规模与年龄跨度，「骑师族」这一称谓的来源亦不详。
