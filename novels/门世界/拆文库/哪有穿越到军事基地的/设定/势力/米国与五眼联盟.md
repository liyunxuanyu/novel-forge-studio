# 米国与五眼联盟

- 类型：国家

## 核心人物

- `角色/弗雷德.md`：米国总统，第22章至第102章期间是米国与华国正面对抗的最高决策者，别名米国总统；克莱德是替他伪造证据的情报线负责人，凡诺、卡文是军事执行与参谋，曼顿是他国内的分裂对手。
- 曼顿：德州石油大亨，第81章前后在资本聚会上站出来牵头组建跨东西海岸的资本联盟，宣布只给弗雷德一年时间（原文见关系表第79至81章相关记录）。
- 麦克斯：米国军方代表，第43章当众反驳「不认为已到危机时刻」。
- 什布尔：米国总统（后期），第800至804章三大舰队与锁眼卫星全部失联后光速投降，在东大舰船上签下投降协议。
- 托斯特拉：第1181至1190章联军指挥官，下令发射战斧打击沿海城市、要求立本南棒舰队打医院与学校。
- 莱斯特：第1193至1195章被以战争罪逮捕并签下条约的战犯。
- 亚历克斯：第791至796章米国舰队旗舰指挥官。

## 立场倾向

对主角一方为敌。第3章同日，米国、五眼联盟与立本在华情报系统集体断联，隐性对抗由对方失手开场。第22至102章由弗雷德主导正面对抗，走的是司法讹诈、舆论战、核试与舰队施压的组合拳；第58至64章西太平洋战争打成战败国，撤出东亚、交还琉虬管辖权并允许华国在九州岛驻军。此后米国长期处于「知道对方强、无法反制」的状态：第628章前后被迫公开表态帮东大封锁南极海域，第791至805章被单舰与金属球打到全境停电断网并投降。到第1142章，米国国内已沦为被本宇宙全域监控、由外部力量执法清算的对象。

## 与其他势力的关系

- 米国 → 华国：由隐性技术竞争到公开战略对抗（第12章，因为华国突然官宣载人登月，米国情报口失手）。
- 米国 → 华国、立本、南棒：由施压方到战败方（第55至64章，因为下令开打却遭电磁脉冲覆盖，五艘核动力航母被完整俘获）。
- 米国 → 环球矿业（华国企业）：由依法调查到明抢控股权（第43章，因为反倾销判决索要绝对控股权，最终未拿到任何股权）。
- 米国 → 立本、南棒：由主从盟友到事实上的指挥关系失效（第55章，因为米军事前未通报便自行开火，两国靠天上火团才知道已经开打）。
- 米国 → 本宇宙华国：由暗中谋划联手施压到被迫公开配合（第628章，因为本宇宙派修长战舰贴着领空高度线横穿米国本土、掠过白宫上方）。
- 米国 → 本宇宙华国：由战场对手到签降书的一方（第798至804章，因为西海岸工业被犁掉三分之二、三十多州停电断网，总统什布尔光速投降）。
- 五眼联盟 → 本宇宙华国：由窃取情报到触手被整体斩断（第3章，因为237计划立项，集体断联且无从解释）。

## 关键事件

- 第3章：米国、五眼联盟和立本在华国的情报系统集体断联。
- 第12章：华国官宣载人登月，米国情报口完全没有消息，被打了措手不及。
- 第19章：米国驻军以家人与女友性命相逼，驱南棒士兵越境行凶。
- 第22章：弗雷德因华国宣布地下核爆而怒摔茶杯，下令太平洋核试。
- 第29至30章：弗雷德自认三方面被超过，强令启动重返月球并抢在华国之前发射。
- 第32章：SLS火箭发射200秒后箭身剧烈抖动，发射失败，三名航天员罹难。
- 第43章：米国对华国1320家公司发起反倾销调查，法官勒令环球矿业移交控股权；弗雷德在五角大楼摊牌并点名环球矿业。
- 第48章：弗雷德摔文件断定华国所为并定下堵门计划。
- 第54至55章：弗雷德发视频下最后通牒索要环球矿业股份，下令开打，米军击落返航的无人歼10。
- 第56至57章：吴统按计划发射十八枚动能弹，电磁脉冲让护卫航母的战斗机编队成片坠海，米军全舰队除动力与弹射外系统全毁。
- 第61至63章：弗雷德承认失败、不敢回白宫，米国转入东京和谈。
- 第79至81章：米元石油霸权倒塌、犯罪率暴涨500%，德州与圣弗兰州闹独立，弗雷德捏碎线报怒吼绝不允许；曼顿牵头资本联盟并要求只给联邦政府一年时间。
- 第92至95章：德克萨斯公投独立，弗雷德下令出兵悬赏，星条旗就着寒风落下。
- 第101章：战机低空飞掠投弹后，弗雷德被迫签署停战协议。
- 第628章：本宇宙派修长战舰贴着领空高度线横穿米国本土、掠过白宫上方，米国与某联失去继续施压的空间。
- 第630章：本宇宙派金属球融掉雪墙，把四名濒绝境的米国空降兵送回米国南极科考站。
- 第791至798章：袁宏单舰出击，导弹与战机如断线风筝坠海；赤红金属球把航母连人熔铸成金属外壳，火球半径达两百米，五角大楼断电、全米三十多州停电断网。
- 第799至804章：外交部门确认米国投降，什布尔带着立本、南棒首脑在东大舰船上签下投降协议，米国在西太的驻军全部让出并百倍黄金赔偿。
- 第1142章：UEG总部被外星人空降，米国警卫队将军口头强硬维护主权，实际改口去抓放飞无人机的人。
- 第1181至1190章：托斯特拉下令发射战斧打击沿海城市，八国联合舰队在不到一小时内被东大岸防部队以饱和打击葬在海底。
- 第1193至1195章：莱斯特等被以战争罪逮捕并签下条约，联合国将转移到该地。

## 组织与实力

结构上以总统与军方、情报线、资本集团三层构成，三者并不同心：弗雷德掌握总统层级的军事与舆论动员权，情报线负责人克莱德替他伪造证据，而各州由大资本家控制、随时可能用脚投票，第79至81章已出现曼顿牵头的跨东西海岸资本联盟。原文明确写出米国「是伪装成国家的大型公司」。规模与技术水平的硬数据：第43章一次性对华国1320家公司发起反倾销调查；第48至55章可动用五艘核动力航母；第54至57章一支西太平洋联合舰队在电磁脉冲下全部系统损毁；第51章前后卫星可被华国抛网罩住并拍下航母位置；第791至798章面对单舰时全无还手之力。其技术水平在第3章被判定为需要华国数十年追赶的对象，到第791章已与本宇宙形成代差。五眼联盟在本档案中只以第3章「在华情报系统集体断联」这一处硬事实出现，其余成员国的具体情报与军力原文未明确。
