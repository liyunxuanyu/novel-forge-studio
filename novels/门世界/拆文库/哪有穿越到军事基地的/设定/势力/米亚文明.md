# 米亚文明

- 类型：文明

## 核心人物

- `角色/卡卡.md`：米亚文明一方的领航员，原驻掩体宇宙的钢铁星球，第989章交接岗位后离港远行，被237计划接收为新成员。他熟悉米亚文明的空间门与掩体宇宙技术，能给出展开时限、指数膨胀门槛与边界控制方面的判断。
- 米亚文明领航员（前任）：第880至885章主动向本宇宙发来通讯并作出警告；第907至933章由暗中观察者转为共同战线的合作准备关系，第910章交出自己文明抢反中子星的完整经验与过程数据，第931章倾囊交出晦星改造数据并警告小心馈赠。
- 艾莫：第989章接手米亚文明的警戒岗位，与卡卡完成交接。
- 主光脑与光脑：米亚文明的机器决策与辅助设备，第989章下令交好人类以换取技术与信息；第984章光脑退出通道时碰到通道壁，牵连一艘冥海文明飞船后由领航员决定隐瞒。

## 立场倾向

对主角一方由中立观察转为友方。第880至885章第一次接触时，米亚文明既出于惺惺相惜给出忠告，又始终保留核心秘密、担心人类是亚空间核心派来的卧底；第888章前后领航员判断人类某些技术甚至比米亚人更先进，倾向继续观察并认为值得接触。第910章起立场明确转向同一条战线，把人类当作唯一对等的同伴。第987章米亚文明正式提出入伙，被荷洛斯质疑是否会被反向渗透，最终以公开自身舰队与战星运行数据、沟通只留一人的条件加入，成为受条件约束的准盟友。第1219至1221章，卡卡自己彻底否定了米亚文明原有的掩体宇宙路线，并庆幸本文明选对了合作对象。

## 与其他势力的关系

- 米亚文明 → 人类文明：由未知敌对嫌疑到已开始谈判的潜在同盟候选（第880至882章，因为领航员主动发来通讯并预告探测器到达）。
- 米亚文明领航员 → 人类文明：由善意提醒到戒备提防（第880至882章，因为朱老回答本宇宙知道亚空间和无限界中潜藏着敌人，领航员怀疑人类是派自爆卡车来探底）。
- 米亚文明 → 本宇宙人类：由暗中观察者与炫耀者到共同战线的合作准备关系（第910章，因为朱老索要抢星与全身而退的完整细节并确认已下决心）。
- 米亚文明 → 人类（朱老）：由半透明技术交换到互赠信息的同路人关系（第925至933章，因为人类真的拿出了反中子星碎片并说出「未知文明馈赠」）。
- 米亚文明 → 冥海文明（赛缇丝）：单方面隐瞒的加害关系（第984章，因为光脑退出时碰到通道壁，加速通道崩溃并牵连一艘冥海文明飞船，领航员决定当作不知道）。
- 米亚文明 → 本宇宙：由陌生文明到受条件约束的准盟友（第987章，因为米亚文明提出入伙，荷洛斯提出反向渗透疑虑）。
- 本宇宙 → 米亚文明：由通讯两端的对话关系到线下共事（第989章，因为外界回信同意由237计划全权负责米亚文明事宜）。

## 关键事件

- 第880章：天灵截获自称没有恶意的未知通讯，两个无人探测器在地外相遇，双方互报文明称呼为人类文明与米亚文明。
- 第880至885章：领航员郑重警告不要在宇宙中随意完全能量化、否则监视者会直接毁掉文明，并交代亚空间核心是观察者的造物、米亚文明抢来设备造出与显体宇宙一般大小的三层掩体宇宙藏了进去。
- 第883至885章：领航员有限度交底后转为暗中观察，人类得到观察者规则、掩体宇宙概念与风暴使用权；领航员判断人类技术整体在霸主级、某些技术甚至比米亚人都先进。
- 第888章前后：领航员判断人类值得接触，米亚文明保持幕后观察。
- 第907章：朱老试探晦星基底来历，让米亚领航员由得意转为惊愕。
- 第910章：领航员决定将自己文明抢反中子星的经验与数据详细告诉人类。
- 第911章：米亚文明被记为抢反中子星的先例，本宇宙据此定下冲入无限界的计划。
- 第922至924章：荷洛斯由方景的嘀咕推出本宇宙被类掩体宇宙结构包裹，判定米亚文明走在正确道路上。
- 第925至927章：领航员承认人类是「同道」，交代晦星原理、缄默者的身份与规避攻略，并说出笼罩整个宇宙的大过滤器。
- 第930章：反中子星被拖到图腾卡港口覆盖遮蔽膜，朱老取一份样本去试探米亚文明。
- 第931至932章：领航员被反中子星碎片震住，全力分析改造晦星的数据，并警告人类小心那份馈赠、以特罗迪亚克文明覆灭为例说明馈赠是死亡诱饵。
- 第947章：朱老再访米亚领航员，得知金属板记录是为对抗缄默者、宇宙之外是无数宇宙光点。
- 第976章：领航员为多了一个同路者而高兴，光脑提醒他别忘了沉睡至今的目的，主光脑下令交好人类以换取技术与信息。
- 第984章：光脑退出通道时碰到通道壁并加速通道崩溃，牵连一艘冥海文明飞船，米亚文明选择隐瞒。
- 第987章：米亚文明提出入伙，以公开舰队与战星运行数据换取加入，被加上沟通只留一人的限制。
- 第989章：卡卡交接领航员岗位后离港远行，抵达空间门基地由237计划列队迎接。
- 第992至999章：卡卡在基地巡视时听到罐中异响并按响警报，一度被当成闹乌龙，随后与周元一起翻盘，确认闯入者是冥海文明的赛缇丝。
- 第1119章：卡卡宣布晦星展开成功，掩体宇宙成为实际存在。
- 第1219至1221章：卡卡从被动探测器数据里筛出鸿巡不加加密的对话并第一时间上报，认定米亚文明的掩体宇宙路线完全错误。

## 组织与实力

结构上以领航员、光脑／主光脑与沉睡中的文明主体构成：领航员是外出寻找盟友与对外沟通的执行者，主光脑是机器决策方，文明主体长期沉眠。技术水平按原文硬数据：第880至885章已造出与显体宇宙一般大小的三层掩体宇宙并藏了进去；第883至885章人类判定其技术整体在霸主级；第888章前后其虫洞与时空技术连米亚人都搞不懂人类的部分做法，说明双方各有一项对方不具备的技术。规模上，米亚文明沉眠几亿年，其钢铁星球与掩体宇宙基地是主要据点，领航员交接时的警戒由主光脑辅助。第931章之后米亚文明已无独有筹码，其晦星改造数据与抢星经验已全部交予人类。米亚文明全体能量化的具体程度、族人数目与掩体宇宙的层数细节，原文未明确。
