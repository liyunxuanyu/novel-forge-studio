# 大虾文明

- 类型：文明

## 核心人物
- 母虫：大虾文明的最高号令源，其指令对全族具绝对约束力。第1137章约翰逊念出母虫指令后，上百只互殴的大虾瞬间列队；第1149章约翰逊回母舰当面觐见母虫；第1156章母巢进驻太阳系成为木星卫星；第1153章母虫凭感知与宇宙常数确认这是新生宇宙，第1154章说出听过「鸿巡文明」这个名字。原文未明确母虫的名号与生理形态。
- 约翰逊：大虾文明一方的成员，担任舰队对人类的通讯与交涉代表，后期成为大虾与本宇宙之间的联络人（第1131章发出狭管通讯要求接回同类；第1138章念出母虫指令、广播召集数万大虾；第1141章处决巴普洛后接走威库斯；第1147章向朱老抛出工兵船失联；第1164章随本宇宙舰队抵达破碎空间）。
- 威库斯：流落地球的大虾一方人物，因被燃料感染而变成半人半大虾，长期藏在人类难民营里等待同类归来（第1134章被燃料感染、与舰上工程师立下三年之约；第1135章藏身难民营、捏着铁片小花延续三年送花的习惯；第1141章被掀开顶盖拽出、三年之约当面兑现；第1148章彻底变回人类并移居东大）。

## 立场倾向
对主角一方由被监督对象转为附庸型合作者：第1135章朱老拍板先监督大虾完成自身事务再展开交谈，第1156章母巢进驻太阳系成为木星卫星、母虫由「要求同行」升级为整巢进驻，第1164章随本宇宙舰队抵达破碎空间、以母虫指令为准配合行动。
对UEG与米国涉事者由追凶到清算：第1138章喝令勾结人类者出列，第1140章处决上千只同类，第1145至1146章处决四名米国议员。
方景个人倾向不出手，第1135章最终服从本宇宙利益立场。

## 与其他势力的关系
- 大虾 → UEG：由被私下抓捕做活体实验到当众清算（第1136章司长当众点破巴普洛勾结UEG抓捕拐卖大虾活体的罪状，第1141章约翰逊公布巴普洛活体肢解的画面，因为要给被活体肢解的大虾讨命）。
- 大虾 → 米国议员：由调查到当场行刑（第1145章动力装甲大虾砸穿国会楼顶、约翰逊一枪击杀叫骂的银发议员，第1146章念出四名议员罪状并当场行刑）。
- 大虾 → 东大：由误判到合作（第1124章东大拒绝背书并称会把涉事名单交出去，第1130章张庆海以「平行世界的东大」说法谈成合作，第1132章东大代表宣布环月舰队担任公证第三方）。
- 大虾 → 本宇宙（237计划）：由互相试探到情报互通与同行（第1135章朱老拍板先监督后交谈，第1147章约翰逊向朱老抛出工兵船失联，第1153章母虫承认这是新生宇宙后转为配合方，第1156章母巢进驻太阳系，因为人类说法被自家数据印证）。
- 大虾 → 移民署与巴普洛：由管理方与被管理者变为被威慑方与威慑方（第1137章母虫指令后大虾列队齐声回应，第1136章司长当众点破巴普洛的罪状并拒绝相救）。
- 约翰逊 → 威库斯：三年之约由立下到兑现（第1134章立约，第1141章当面兑现并以红色夹克相认，第1148章了结）。
- 大虾 → 威库斯：第1148章由母舰医疗设备完成由大虾到人类的转化，因为约翰逊要替威库斯避开米国报复。

## 组织与实力
大虾是虫巢社会，母虫指令具绝对号令力（第1137章、第1138章）。人口方面，移民署在册一万三千六百二十七，与实际数万规模对不上（第1138章）。
武装与设施方面，拥有圆盘飞船舰队、母巢星球与母舰医疗设备（第1131章、第1149章、第1156章、第1141章）；黑色燃料可把智慧生物转化为同类（第1135章）；第1147章有工兵船失联。第1138章另有约翰逊下令处决上千只同类、清除大虾帮派的记载。
原文未明确其族属与种族的正式名称（原文仅以「大虾」「小虾」「同类」指称）、感染燃料的机制、三年之约的具体条款，以及其文明疆域规模。
