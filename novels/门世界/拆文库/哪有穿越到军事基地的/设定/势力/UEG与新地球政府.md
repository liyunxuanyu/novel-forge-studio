# UEG与新地球政府

- 类型：国家

> 本档案按同一文件名收两类政权：**UEG**（殖民地联合地球政府，以及掩体宇宙《第九区》世界中以「UEG」指称的公司与政府复合体）与**新地球政府**（反抗军在击溃公司第一分裂舰队后组建的政权）。原文未明确两处「UEG」是否同一政权，此处按章号分别标注。

## 核心人物
**UEG（死亡空间世界）**
- 执行董事：公司体系的高层，第1039章求死被钱必武制服、换出公司反人类罪证据，第1075章被钱必武当面击碎幻想，最终被吊死在街道路灯上。
- 斯特拉：维兰德公司第一分裂舰队的指挥官，第1044章率舰队集结出征，第1049章在陨石带遭反抗军主动撞击、舰队减员七成，第1052章定下屠灭矿星与灭口计划，第1054章自杀未遂被活捉，第1059章在审讯中醒悟并交代教会布置。
- 塔特：飞哈殖民地的指挥官，第1062章收到斯特拉急电后拉响警报，第1063章弃舰逃跑。
- 泰德：矿业方人员，第1071章向同伴透露与教会合作、需要大量尸体研究无限能源。
- 艾尔马克：引擎研究所人员，第1072章为换取技术主动提出现点现杀上千万人。
- 冯星：矿业公司负责人，第1076章主动交出治理权。

**UEG（掩体宇宙《第九区》世界）**
- 阿特尔：被UEG高层留在总部顶罪、并用吐真剂灌成傻子以对抗读脑（第1140章）。
- 艾斯特总统：原文未标注其出场章号；第1144至1146章一段记述中他主持国会应对危机，亲眼见议员被处决，威严与脸面尽失。
- 四名米国大议员：第1144章被约翰逊从记忆中查出参与残害大虾，第1146章被念出罪状并当场行刑。

**新地球政府**
- 钱必武：反抗军领袖，第1056章宣布组建新地球政府并成为最高负责人，第1075章当着执行董事的面宣告新政权、点明殖民地已被拿下。
- 胡猎：新希望号舰长，第1025章获授权组建正规舰队，第1103章随庞海抵近打击轨道、请令处理神盾星系。
- 赵世海：反抗军维拓基地的指挥者之一，第1053章与钱必武劫后重逢，第1171至1203章转入东大合作线。
- 叶明军：反抗军骨干，第1068章被救出后转而关心治理问题。

## 立场倾向
**UEG（死亡空间世界）**：对反抗军为统治与围剿方，第1010章方景靠监听得知世界被公司控制、各国政府成傀儡；第1044至1050章以公司舰队与教会舰队合流镇压；第1076章政权更迭后被推翻。
**UEG（掩体宇宙）**：对大虾为加害方，第1136章司长当众点破巴普洛勾结UEG抓捕拐卖大虾活体；第1133章其军工复合体想让东大顶罪；第1140至1146章其高层、股东与议员被追出并清算。
**新地球政府**：对主角一方为盟友，第1073章钱必武率联合舰队穿云而出、宣布公司高层被捕；对本世界各国政府为接管方，第1076章各国政府被迫派人赴会。

## 与其他势力的关系
- UEG（死亡空间） → 反抗军：由统治与围剿到被推翻（第1010章世界被公司控制、各国政府成傀儡，第1028章公司指挥官阿萨的舰队被反抗军曲速直撞洞穿，第1073章钱必武宣布高层被捕，第1076章政权更迭公开）。
- UEG（死亡空间） → 统一教会：由协作到一同覆灭（第1044章教会舰队作为斯特拉的援军参战，第1050章教会舰队合流，第1076章两者中枢同时被清算）。
- UEG（掩体宇宙） → 大虾：由私下抓捕做活体实验到被清算（第1136章罪状被当众点破，第1140章高层处决上千只同类后播放记忆证据，第1141章公布巴普洛活体肢解的画面，因为要以牙还牙为被活体肢解的大虾讨命）。
- UEG（掩体宇宙） → 东大：由想让东大顶罪到被反转（第1133章军工复合体想让东大或环月舰队替他们挡下大虾的审判，第1132章东大代表宣布环月舰队担任公证第三方）。
- UEG（掩体宇宙） → 本宇宙：由被调查对象到被全域监控与接管（第1142章本宇宙以联合调查组名义协助大虾追凶、投下天灵的种子，因为该宇宙人类有缺陷而特殊对待）。
- 张年变 → UEG股东与董事：由追查者与被追者变为守株待兔的猎手与田边被熏的老鼠（第1143章，因为查出UEG高层躲入地下核防工程，改从通风井投放加料催泪瓦斯弹逼其自行出洞）。
- 新地球政府 → 反抗军：第1056章由反抗军宣布组建（钱必武在吊死过公司高层的广场上宣布胜利并号召消灭蛀虫、夺回世界）。
- 新地球政府 → 各国政府与矿业公司：由军事胜利转为接管与合法性（第1076章各国代表赴会途中看到路灯下悬挂的成排尸体，冯星主动交出治理权）。
- 新地球政府 → 矿工：第1056章钱必武的威望在矿星达到极点、巅峰。
- 新地球政府 → 本宇宙：第1073章钱必武率联合舰队穿云而出，第1103章胡猎随庞海抵近打击轨道。
- 钱必武 → 矿星矿工：从武装首领与矿工的关系转为领袖与治下民众的关系（第1056章）。
- 钱必武 → 公司高层：从被围殴的受害者转为被公开宣判的宣告方（第1073章，因为身后是刚刚歼灭太阳系所有防卫力量的舰队与对准大楼的侧舷炮）。

## 组织与实力
**UEG（死亡空间世界）**：由公司推翻主权殖民地联盟政府后建立（第1016章），统治人类世界两百年（第1048至1070章一段记述）。其掌握太阳系防卫军、行星防御阵地与木卫重炮基地（第1071至1100章一段记述）；第一分裂舰队近千艘（第1048至1070章一段记述）；地球方向由几十艘神盾舰用空间泡包裹、只隔绝不传送（第1074章）。第1076章政权更迭后，其地球与百余殖民地的治权移交新地球政府。
**UEG（掩体宇宙）**：是军工复合体、公司与政府高层交织的体系，设有总部、地下核防工程与股东、董事层级（第1133章、第1142章、第1143章）；其影响延伸到米国国会与议员（第1145至1146章）。
**新地球政府**：第1056章宣布组建，第1075章正式宣告；第1073章出场时其舰队已歼灭太阳系所有防卫力量；第1048至1070章一段记述中接管强生、飞哈、托纳等殖民地与投降的旧工作人员，并继承地球与百余殖民地的治权。原文未明确新地球政府的制度细节与完整编制。
