# 霍尔文明

- 类型：文明

## 核心人物

- `角色/霍尔文明领袖.md`：霍尔文明的最高领袖。该文明已完成星系改造、走全体机械化之路，因受某种桎梏而孤注一掷，把整个星系变成一门巨炮。第908章他在大殿内向单膝下跪的机器人道出全体机械化的无奈与桎梏，宣布开战、梭哈一搏；第911章断言守卫沉睡、放走火种并把信息射向全宇宙；第913章宣告障碍排除、完成全部充能；第915至918章用最后一道攻击把亚空间核心与监视者一起抹去；第919至921章下令斩断枷锁、全舰队打击目标星系，随后撤退失败、设备全废，能量被剥离，意识留在被毁的躯壳中如缸中之脑。
- 霍尔文明火种：第911章被领袖下令离开、走得越远越好并遮掩痕迹，是领袖为文明保留延续的安排。
- 霍尔文明战士与作战单位：第916章前后接受领袖排除内部异议后下达的冲锋令，与领袖同心赴死；反对者与摇摆者的子嗣已被提前送走。
- 阿尔诺米（旁证者）：塔罗文明唯一活口，第912至913章由旁观的来客变为关键情报提供者，指出霍尔星系真实结构为空间粒子碎裂流束炮。

## 立场倾向

对主角一方为中立而不可接触的第三方。本宇宙与霍尔文明之间没有任何直接接触，只有单向的远距观测与推断：第908章本宇宙观测台发现霍尔星系环带高速旋转，第909章天火认定那是全方向空间干涉仪，第912至913章阿尔诺米确认其为横跨十万光年的星系巨炮。霍尔文明的真实敌人是维护桎梏的暗中势力、亚空间核心、清理者与监视者，与本宇宙不构成利益冲突，因此本宇宙的立场是静观其变、不跟风突破。霍尔文明本身的立场从未转向，从受桎梏的守方一路打到覆灭。

## 与其他势力的关系

- 霍尔文明 → 维护桎梏的暗中势力：由长期准备到开战（第908章，因为能量化之路被阻断、技术停滞多年）。
- 霍尔文明 → 亚空间核心、清理者：由对立到逐一抹去（第914至915章，因为核心把清理者骗到界壁墙前当挡箭牌，两道攻击将其全灭）。
- 霍尔文明 → 监视者：由被伏击到反杀（第917至918章，因为用整条环带为饵一击灭掉几千个监视者）。
- 霍尔文明 → 反霍尔星系：由视为枷锁到打成碎屑（第919章，因为领袖认定头顶那个反向星系是文明的唯一枷锁，下令全舰队开火）。
- 本宇宙 → 霍尔文明：由旁观战事到跟踪并推断其目的（第916至918章，因为荷洛斯与董教授判断霍尔文明知道内情、要毁灭反霍尔星系）。
- 霍尔文明 → 本宇宙：无直接关系（第908至922章全程只有远距观测，领袖被记为与本宇宙一方无直接接触）。
- 缄默者 → 霍尔文明：由现身到抹除（第920至922章，因为霍尔文明打碎反霍尔星系后暴露舰队位置、耗尽核心能量）。

## 关键事件

- 第908章：霍尔星系经上亿年改造被做成环状星系，星核大殿内领袖确认霍尔文明因能量化之路被阻断而全体机械化、技术停滞多年，决定向维护桎梏的暗中之敌开战；六亿光年外本宇宙观测台把跨星系探测器对准该星系。
- 第909章：环带以接近地球自转的速度旋转，环带恒星因横向挤压瓦解碰撞，整个星系化作恒星风暴；天火认定这是人为改造的全方向空间干涉仪，董教授报告无限界正发生频率吻合的强烈震荡。
- 第910章：本宇宙确认霍尔星系只是扰动无限界壁，朱老当众定下冲入无限界抢反中子星的计划。
- 第911章：霍尔星系环带粒子螺旋能量累积到16%，领袖下令让火种远走并把在反物质宇宙探查到的信息射向其他星系；亚空间核心被界壁扰动惊醒后编造数据把清理者骗到指定位置挡枪。
- 第912章：本宇宙进入战备、上千艘飞船加装反物质宇宙隔膜；阿尔诺米看出霍尔星系是横跨十万光年的粒子流束炮。
- 第913章：阿尔诺米确认霍尔星系是星系巨炮，朱老决定坐等对方动手；领袖清除最后一批反对者后下令核心对阵亚空间。
- 第914章：霍尔星系完成纵轴旋转发动攻击，三万光年宽的环带瞬间少掉六分之一，第一道攻击贯穿界壁墙并将清理者舰队全灭。
- 第915章：亚空间核心卡在界壁墙上被无缝衔接的第二道攻击连同机械半身与血肉半身一同抹去；领袖大笑下令开盾征伐，第三道攻击打出裂缝，霍尔文明沿航迹发起总冲锋。
- 第916章：苏员舰队趁乱进入反物质宇宙，撞上巨型超新星后探测波被瞬间反射，发现异常引力点。
- 第917章：苏员与自称同为潜入者的锥形飞船互相识别后各走各路，监视者苏醒并准备伏击。
- 第918章：霍尔文明用整条环带为饵，一击灭掉几千个潜伏在舰队后方的监视者并找到反霍尔星系。
- 第919章：领袖认定反向霍尔星系是文明的唯一枷锁，下令全舰队开火把它打成碎屑；朱老判断跟风突破会被秋后算账，下令静观其变。
- 第920章：显体宇宙一侧一击轰碎霍尔星系，缄默者现身剥离霍尔舰队能量，领袖意识到自己也是机器人。
- 第921章：缄默者撞毁数万飞船与几百战星，人类突击舰队用引力干涉仪拖着反中子星撤离。
- 第922章：缄默者只碾碎跑得慢的十几个文明；霍尔文明一个照面被灭，本宇宙确认存在巨大技术代差，并决定必须掌握反制手段。

## 组织与实力

结构上以领袖与全体机械化的机器人、舰队构成，内部异议通过清除取得一致，反对者与摇摆者的子嗣被提前送走。规模与技术水平的硬数据：第908章霍尔星系经上亿年改造成为环状星系，是整座星系级的设施；第909章环带以接近地球自转的速度旋转，恒星瓦解后化作恒星风暴；第912至913章其真身是横跨十万光年的空间粒子碎裂流束炮（星系巨炮），射程与威力以星系为单位；第914章攻击瞬间让三万光年宽的环带少掉六分之一，贯穿界壁墙并全灭清理者舰队；第918章一击灭掉几千个监视者；第920至921章被缄默者剥离能量后，数万飞船与几百战星被撞毁。霍尔文明全体机械化的具体起因、桎梏的来源与其族人数量，原文未明确；本宇宙与霍尔文明全程无直接接触，所有实力数据均来自远距观测与事后复盘。
