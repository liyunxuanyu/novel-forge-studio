# 赖亚人

- 类型：文明

## 核心人物

- `角色/白鲨.md`：赖亚人掠夺舰队的首领，本族为圆环形生命形态，在联盟兑换所一线靠内线情报猎杀商船；第750章率三百二十七艘舰队在小行星带后方吊住吴统舰队，第753章被俘，此后成为本宇宙手中的俘虏、实验体与劳改犯。
- 大长老（最高大长老）：赖亚人的宗教与族群领袖，第812章发现无限界裂缝重启，第813章下令储存七成能量并开放禁地，第829章前后被袁宏以白鲨被俘与同归于尽施压，被迫同意引见。
- 赖亚人长老：第764章前后感知中断后对白鲨生疑，对「消失而非死亡」无法解释，决定等待答案。
- 罗罗：与白鲨一同被俘的赖亚人，第762章被白鲨以同族安危换取自身安全时舍弃。
- 银鲨：第750章前后与白鲨同盟的赖亚人掠夺者，因白鲨情报有误而迁怒，其舰队随后全灭。

## 立场倾向

对主角一方由敌对方到被彻底压制的对象。第750至763章，赖亚人掠夺舰队是本宇宙在联盟地界的直接对手，白鲨被俘后其族群转为实验体与情报来源。第812至829章，赖亚人母星被袁宏舰队进入，其狂欢中的全族防御空门大开，大长老在本宇宙的施压下失去讨价还价空间、只能同意开放禁地。此后赖亚人失去重返黄金时代的可能并被卷入战争，母星被本宇宙的中子炸弹摧毁，族人成为需要安置与补偿的难民。赖亚人对本宇宙没有形成过有组织的反击，其立场变化是被动承受式的。

## 与其他势力的关系

- 赖亚人 → 本宇宙：由陌生双方的对峙到施压方与被迫配合方（第812至829章，因为袁宏舰队已开到大气层内、最差情况是与整颗行星同归于尽）。
- 赖亚人 → 联盟：由神国的弃民到白嫖能量的对象（第812至821章，因为董教授确认赖亚星是无限界的排泄口，逸散能量属联盟）。
- 赖亚人长老 → 白鲨：由已处置的叛逆者到下落不明的悬案对象（第764章前后，因为神坛核实不到白鲨与无限界的联系）。
- 白鲨 → 罗罗及同族：由一同被抓的同伴到被舍弃的一方（第762章，因为朱老同意给出保证，白鲨只为自己要到安全保证）。
- 赖亚人 → 本宇宙：由被卷入战争到失去母星并成为难民（第826至829章，因为袁宏舰队自毁探测器、引爆赖亚星中子炸弹后撤离）。
- 本宇宙 → 赖亚人：由交战与实验对象到给予补偿的安置方（第828至829章，因为袁宏以恒星源补偿赖亚人难民）。

## 关键事件

- 第750章：白鲨率三百二十七艘舰队在小行星带后方吊住吴统的二十四条船，备好针对性武器。
- 第753章：主力被全歼，白鲨被俘并供出内线阿拉德，随后被电击审问。
- 第754至756章：方景连续电击白鲨、副手与全舰十六名舰员，荷洛斯不走流程直接开电、重复十次并植入探测器，赖亚人沦为实验室研究样本。
- 第757章：白鲨在审问室彻底出卖阿拉德，赵光耀由此定下杀心。
- 第761至762章：白鲨在先锋矿场昏倒，醒来后供出无限界赐福传说，指出中星位置与能量节点吻合，并弃同族于不顾只求保证。
- 第763章：荷洛斯操控白鲨穿行纯能量舱，凝出能量拟态手。
- 第764章前后：赖亚人长老因感知中断而对白鲨生疑。
- 第812章：袁宏登上十公里级掠星舰远征，赖亚人大长老发现无限界裂缝重启。
- 第813章：赖亚人身为神国弃民重享能量海，大长老下令储存七成、开放禁地。
- 第814章：章直言发现赖亚人能量化征兆并上报，朱老下令盯紧联盟。
- 第815至816章：掠星舰进入赖亚人识别区却发现母星防御空门大开，赖亚人防卫部队混在狂欢群里。
- 第817章：董教授判定逸散能量属联盟，袁宏以白鲨被俘逼开禁地。
- 第818至820章：舰队进入海底禁地，粒子探测器逆流穿透裂缝薄膜，探测器自毁、舰队经太空桥撤离。
- 第821章：袁宏回航赖亚星。
- 第826章：袁宏舰队趁空窗探索无限界，自毁探测器并引爆赖亚星中子炸弹。
- 第828章：朱老训话要求舰队常驻太阳系，袁宏以恒星源补偿赖亚人难民。
- 第829章：方景告知凯·迪斯十二主星被毁，袁宏完成对赖亚人的善后。

## 组织与实力

结构上以神权与族群长老制为核心：最高大长老掌握禁地与全族决策权，长老负责核实与处置叛逆者，防卫部队与掠夺舰队承担武力，普通子民在能量海重启后全族狂欢。规模与技术水平按原文硬数据：第750章白鲨一支舰队为三百二十七艘，对上吴统的二十四条船时备有针对性武器；第754章其一支舰队的舰员规模被写作全舰十六名；第812章赖亚人被明确为「神国的弃民」，母星防御在狂欢期间空门大开；第818至820章其海底禁地可由外部粒子探测器穿透裂缝薄膜，说明其对无限界裂缝的管控只停留在禁地禁令层面，无技术封锁手段。第826章赖亚星被本宇宙的中子炸弹摧毁，母星与全族生存基础一并失去。赖亚人全族人口、军队总数与能量化技术水平的具体数值，原文未明确。
