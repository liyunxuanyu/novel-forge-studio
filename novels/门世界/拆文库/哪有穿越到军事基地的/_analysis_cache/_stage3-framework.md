## 判断说明

这本书不能按单一主角升级流来读。第1-3章把方景立得很实，但第3章「借机生蛋，多元宇宙华国的设想」一确立，叙事重心就从「我变强」改写成「这台机器能为华国搬回什么」，237计划当夜立项，主角的功能是唯一通道与决策参与者，而不是战力天花板。真正的升级轴是技术与文明的刻度：从外骨骼、载人登月，到强人工智能、奇异能量、歼灭舰、太空桥、星环，每一级都由「进入世界—取材—入库—国力抬升」四步兑现。对抗侧则按米国/五眼 → MOSS → 霸天虎 → 托纳人与侵蚀体 → 塔罗舰队与清理者 → 矿业公司 → 印和文明 → 艾克罗与鸿巡舰 → 灵俏文明逐级换代，换代依据是「对手的宇宙尺度」，而非主角的个人境界。

对剧情单元切分的含义是：切分依据应当优先取「世界换代、对手换代、技术换代、机器线索推进」这四个节点，而不是主角的个人成长节点。判断依据的三条硬证据：一是世界换代有机器红点与《设定集》为界（第6章识别流浪地球、第326章判定变形金刚、第1176章机器加载13%），二是技术入库有实物产出（外骨骼、火种源、奇异能量、汲取进化器、空间干涉仪），三是对手换代伴随明确战损（第476章抹去贝诺塔恒星系、第826章联盟十二主星被抹、第1226章小宇宙爆炸波及银河系）。单元内部可容忍多视角切换与主角缺场（如第901、976、1001、1201章均由异文明视角承担叙述），但每个单元必须能回答「这一单元里华国或人类拿到了什么不可替代的东西，或失去了什么」。

同时要注意两类容易被误判的章节：一是纯异文明视角的过场章（第976、1001、1201章），它们承担文明等级与威胁尺度的信息披露，不是水章；二是政治、外交与民生类章节（第576、651、1076章），它们承担「国家能力被外部承认」的推进功能，不应被判为无主线推进而强行合并。
