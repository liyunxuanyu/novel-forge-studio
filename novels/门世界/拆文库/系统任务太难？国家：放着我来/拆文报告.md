# 拆文报告：系统任务太难？国家：放着我来

## 基本信息

- 书名：系统任务太难？国家：放着我来
- 作者：超级吹宝超级吹宝泡泡糖
- 章节数：343 章（第343章为连载最新章，不是完结章）
- 总字数：75.1 万字
- 题材：上交国家 / 系统流 / 人物成长。现实向底色，系统是唯一的超自然来源
- 主角：李策，23 岁，档案里奖惩记录全为零的普通青年，对策小组内部代号 001
- 共同主角：陈卓，省国安具体事务负责人，李策案子的第一接触人
- 金手指：来历不名的系统；失败惩罚是抹杀本人并牵连家人，惩罚范围逐级上推到三代血亲
- 拆文规模：43 个剧情单元、191 条人物关系、48 个节奏锚点（AX）、20 个爽点循环（RH）、25 个情绪触动点（TR）、14 条关键双时间线（EV）、5 张情绪模块卡（EM）、10 条机制索引（M）

## 核心发现

1. **它把系统文最大的爽点反着写。** 别的系统文靠"独吞奖励"兑现爽感，这本的核心动作是上交：奖励一律先交给国家（第4章起从未破例），由专家定级、国家消化、再以分红、实物、编制反向流回主角。读者追的不再是"我能拿到什么"，而是"这次上交能换回什么"。这是全书最值钱、也最难替代的结构选择。
2. **压迫源始终只有一个，而且永远可量化。** 抹杀倒计时 + 牵连范围。准备期从第1章的 7 小时，到第321章的 15 天；惩罚范围从一人扩到双亲再到三代血亲，李策自己推到"夷三族（含妻族）"，因此把婚期推到四五年之后。惩罚没有谈判空间，这是全书唯一的发动机。
3. **张弛几乎对半，是刻意的。** 全书紧张 28.0% 对轻松 27.6%（章级 129:122）。作者自述慢热起步，结构上却把高压段与日常段严格交替：日常段负责消化情绪并埋入隐患，是下一段的引信而不是空转。
4. **反应层由配角和机构承担，不由主角承担。** 主角负责提供事实，陈卓、林院士、于博士、DIA 总评估组负责判断和震惊。连打脸都交给对手自己查数据、自己改口——爽点载体是"对方自行脑补出一个更高的身份"，不是主角的姿态。
5. **代价由配角支付，且由组织定价。** 周哲用命换一部能拨通使馆的电话（第216-217章），随后国家用追授一等功、档案调入联参情报局、载入军史与地方志、烈士陵园安葬来给这笔账定价（第229-240章）。主角只拿到长期亏欠，不做即时结清。
6. **最大悬念被制度化了。** 系统来历与目的至今无解：第191章"被遮挡的模块"、第139章面板间距增加、第172-173章马赛克变淡、第289章三种互相冲突的模型，全部悬置。第343章以未结算的等离子系奖励收尾，是连载断点而非收束点。
7. **代价不在主角身上。** 主角从头到尾没有真正失去过什么——亲人活着、公司在扩张、身份在升级。这让它读起来安全，但也让"怕失去"这条读者需求始终靠外部威胁兑现，无法内化。

## 黄金三章评分

三章总评 3 / 3.6 / 2.6（第1章 3、第2章 3.6、第3章 2.6），逐章扣分点如下。

- **第1章「我真的有系统」3 分。** 扣分点：①第500字到约第2000字没有任何情绪回甘点，读者要跨过约1500字的对话拉锯才等到任务内容揭晓；②全章唯一一次"释放"只有约150字，铺放比 14:1，是三章里铺得最久、放得最短的一章；③反应层只是"不信"，反应篇幅比约 0.8:1（正常应高于1.5），没有一次真正意义上的释放也就没有配套的震惊；④主角全程零自主决策，坦白是被倒计时逼出来的；⑤"我有系统"这个类型化名词本身是系统文通用形态，钩子的新鲜度有限。
- **第2章「我陪你赌了！」3.6 分，三章最高。** 扣分点：①本章约700字的验证戏之后才给结果，读者等得太久；②"一秒不差"之后刻意不释放，克制虽对，但单章满足感仍薄；③整章零场景切换、零新角色实质进场，节奏近乎停滞；④李策戏份进一步压缩到功能位，全章只有"提供信息 + 承受测试"两个功能；⑤信息全部集中在"国家怎么运作"一侧，系统来历、乱码含义、奖励池边界一律没动。
- **第3章「任务完成！」2.6 分，三章最弱。** 扣分点：①**反应层几乎空缺**，反应篇幅比 0.36:1（正常应高于1.5）——漂移完成后陈卓、张虎、装甲兵没有任何一句反应，直接切到系统面板就收章；②释放只有约290字（漂移）＋约70字（结算），铺放比 6.7:1，读者刚被提起来就落地；③全章六个场景每个都很短，"办事过程"约1160字对主角行动约290字，接近4:1，结构性地把爽感换成了流程感；④主角全程被动，三个"稀里糊涂"写尽失重感，连最后的漂移都是听指令完成；⑤章末附作者留言（非正文），直接切断章尾钩子的余味。
  补充：奖励"商用锂空电池技术"的分量被整体后置到第4章由林院士承担。三章合计只有憋闷没有回甘，这是本书前期在番茄能起量的关键未知数，也是最值得单独研究的一处。

## 读者在追什么

从 `剧情/情绪模块.md` 的读者需求表提炼，八条需求按追读强度排序：

1. **怕失去——要一块随时会砸下来的硬石头。** 失败即抹杀本人并牵连三代血亲，范围逐级上推。对应第1-3章的七小时倒计时、第256-265章推演到妻族、第310-315章的缓婚方案。每次新任务自动重置倒计时，读者永远停在"下一次来不及"。
2. **上交之后我到底拿到了什么。** 上交 → 专家定级 → 国家折算 → 分红/实物/编制反向回流。对应第4-8章定级、第106-109章的飞机与游艇、第121-123章按电量计费的分红。这一条把上交从牺牲改写成正向循环。
3. **想看一个人被整个国家托着走。** 投入层级从军区、海军、空军、舰队一路抬到十二支特战队成建制出国。规格可继续上抬，形成几乎无上限的期待。
4. **高压之后要喘息，但喘息里不能太平。** 日常段必须同时消化情绪并埋入隐患——训练、招人、经营、采购、家宴都是低烈度但有信息增量的载体。
5. **想让内行替我震惊，而不是围观群众叫好。** 掉马对象从路人换成专家团队与机构，震惊由专业鉴定承担，估值只能上行。
6. **想有人替我付代价，而且这笔账被认真记下。** 定价必须由正式机构出手，只靠主角口头愧疚无法替代。
7. **想看到钱和日子一样一样落到手里。** 直升机养护成本、家族办公室、采买与经营的细节，把抽象的上交收益换算成可核对的价格与流程，形成进度条。
8. **想守着一个不允许被回答的问题。** 奖励栏乱码、面板间距增加、马赛克变淡、被遮挡模块拒绝解释。悬念是最大的一盘，但代价是它永远不兑现。

## 故事怎么推进

六条故事线交织，主轴是一条，其余挂靠。见 `剧情/故事线.md` 的 SL 编号。

- **SL-001 系统任务与上交国家的循环（主轴，其余各线都挂在它上面）。** 六个阶段：①第1-3章坦白与验真——真话需被验证，陈卓用桌下计时与突然提问做局，一秒不差后换来未公开的100式坦克；②第4-8章制度接管——林院士二十分钟回电失态、王建国连夜绝密上报、首长拍板，上交从此成为固定后半段；③第55-137章灾害底牌与举国试炼——奖励由技术升级为可消灾的"镇灾"，台风"巨蟹"登陆前被消解，系统升级后逼他以零飞行基础自驾歼-20 飞越宫古海峡，全国试飞力量与三大舰队为一人铺开战场；④第246-255章参与即触发——他当面指出对策小组把因果搞反，不是事件触发任务而是他参与才触发；⑤第266-280章国家工程的公开路演——鳌太线"独自"判定被伪装成景区营业点与索道步道绕开；⑥第327-343章预案内深潜——任务落进早已推演过的备份，海底地震中靠"聆听"把奋斗者号带出浊流，结算未落、惩罚已升至三代血亲。
- **SL-002 能力训练与班底经营（成长线，高压段之间的承接层）。** 陈卓给通道办公司手续、军牌防弹车、运-20 接返父母、王红旗带体能、001 阶梯式社死脱敏训练把"五万人演唱会唱歌"拆成可执行链、柳柳入职与教育部接入谈判。日常型奖励换综合耐力提升20%，他由此确立"用系统奖励补现实漏洞"的自我定位。
- **SL-003 李策与裴舒晚的感情线（依赖 SL-002 的紫金山救人入口）。** 爱马仕店138万的答谢与"不能白要"的底线僵持 → 探病明牌与长辈认可 → 红灯下她先伸手十指相扣、聚会当众介绍"这是我男朋友" → 见家长的摸底 → 送出无烧鸽血红与红山树屋，同一天他推演出惩罚可能升到夷三族 → 对策小组给出"先订婚、四到五年内不结婚"的方案，国安与空军联袂上门摊开条件。阻力不在人物而在系统规则，长辈带来的不是道歉而是条件。
- **SL-004 身份遮蔽与外界冲突（冲突线，由 SL-001 双重供能）。** 地方恶霸与保护伞 → 假身份工程（国家选战略欺骗而非圈禁，伪造人脉、替换族谱石碑、灌输群体记忆，并列出外界四种猜测）→ 二代圈自行误判为白手套、林山海跨海落网 → 综艺现场社会性冲突与舆论战 → 对外说法"被特招入伍参与机密任务" → 元青花大缸与"天宫子弟"。母题：真实身份藏起来，被误认的身份反而更硬。
- **SL-005 非洲被掳与周哲之殉（复仇线，触发依赖 SL-006 的自动接取）。** 只穿睡衣在密闭房间里凭空消失 → 荒原求生与被掳进黑矿 → 以危险本能与黑龙十八手逐个击倒矿工 → 周哲以命换来电使馆的通路 → 紧急代码0X001与四项地貌特征被遥感锁定，蛟龙小队索降突入，亨德森被生擒处决 → 十二支特战队成建制出国扫矿、追授一等功、档案调入联参情报局、载入军史与地方志。母题：代价由配角支付，由组织定价。
- **SL-006 系统来历与遮蔽模块（谜团线，依赖 SL-001 的任务节点逐次暴露，答案至今未给）。** 面板间距增加 → 演唱会结算瞬间马赛克闪动变淡并昏迷三日 → 被遮挡模块出现且拒绝解释、未经选择即自动接取 → 视频被逐帧分析出未曝光的军用级无人机与有源式外骨骼，奖励升级为刑天动力装甲全套图纸 → 第289章三种模型互相冲突仍无定论。母题：信任先行，答案延后。

推进的固定循环是：面板弹出任务 → 李策用国家资源做准备 → 执行中出意外或被围观 → 结算 → 奖励上交 → 专家/高层/对策小组研判 → 面板弹出更难的任务。

## 人物与关系

- **主角层。** 李策出场 320 章，覆盖率 93.3%，是全书唯一近乎全勤的人物。外壳是抠门社畜加社恐爱脑补，内核是怕牵连无辜（第306章给父母定下照顾三代血亲的具体标准）与把红利往制度和工人身上推（第253章）。成长三段清晰：小我为活命而赌 → 自我把奖励兑换成家业、被"抹杀三代血亲"折磨 → 他我主动请缨扫黑矿、把分配制度当成己任。转折点是周哲之死。
- **共同主角。** 陈卓出场 177 章（51.6%），首现第1章、末现第343章，全程在场并推动主线，弧线有触发、有转折、有落点。他的成长是从"凡事先验证"到"以命担保"：第2章布验证局，第114章一旦认定就以命担保，第67章因"镇灾"奖励红着眼直言救人比钱重要，第227章答应带蒋教官扫黑矿，第300章在阳台上看李策谈制度，评一句"他真的长大了"。
- **核心配角。** 苏晴 170 章、王红旗 160 章、裴舒晚 81 章。苏晴是警备局内卫出身，话少、判断先于请示，从执行细则的警卫长成有自己判断的搭档；王红旗是同一套配置里的硬功夫派，黑龙十八手由他所教，护送灵车、三亚到马里亚纳舱外指挥，最后进入对策小组；裴舒晚从"被他救的人"变成"主动要进入他生活的共担者"，感情推进始终与不能说的真相捆绑。
- **191 条关系的走向。** 关系网密度自检前 20 位：李策 145、陈卓 32、王红旗 23、苏晴 21、裴舒晚 20、裴建华 12、阮糯 10、蔡宝珠 8、约翰 8、李学友 8、亨德森 8、林子琛 7、焦老三 6、周哲 6、包文达 6、刘春生 6、裴景朝 5、柳柳 5、林院士 5、林山海 5。方向高度一致，可归成四类：
  - **上行关系逐级加码。** 李策→陈卓从"陌生人→单向坦白"一路走到"由共同应对转为国家层面主导"，中间累计了三十余次状态变化，跨度覆盖全书；这一条是全书关系的骨干。
  - **保护关系持续换名。** 苏晴、王红旗从"陌生人→随行保护"到"被隐瞒者转为对策小组成员"，中间叠加了安保、助办、陪练、生活照料、情感支持多层职能，全程不靠台词升级，靠动作与授权升级。
  - **反派线全部走到定价为止。** 林子琛从观察对象到当众失控、从被父亲弃子保己到随父子落网，第145章判枪毙，此后只在第246章赛车场聚会被追述；亨德森从幕后掌控到被擒、在周哲遗体前处刑，第223章后彻底退场。
  - **代价线只上行不回头。** 李策与周哲从同组难难友到生死之交再到"记得带我回家"，然后是单人亏欠、单人哀悼、单人继承遗志——这条线是唯一以不可逆损失收束的关系。

## 读者知道的和角色知道的

14 条关键双时间线（`剧情/节奏.md`），读者的信息位置几乎全程领先，角色只在"解释权"上领先读者。

- **EV-001**（第1天，7小时36分）：系统绑定、失败抹杀并牵连家人。李策口述 → 第2章对表 → 第148、250、321章扩为三代血亲。读者全知；陈卓起初定性妄想症，后只承认"从100%不可能变成99%不可能"。作用：立住全书唯一压迫源。判断变化：从"疯子讹钱"变成98章后仍被国家抢答的真实规则。
- **EV-002**（第2天，42分36秒前完成）：戴全封闭头盔驾驶WZ-124完成漂移，掌心凭空出现U盘。读者全知；林院士只知材料思路不知来源，王建国与首长只知"某渠道"。作用：第一轮认知反转与释放点。
- **EV-003**（第4-6天夜）：锂空电池定为国家级战略底牌，身份转为绝密专项合作方。读者全知；林院士被拉进终身保密，李策被安排、被保护、被约束。作用：确立"上交—反馈—再下任务"循环。
- **EV-004**（第68-72章）：镇灾定价为一次一灾一百亿、四次共四百亿，李策被明确为白手套与鱼饵。读者全知；外界只知"锂空电池来历"，李策自己知道这是伪造身份。作用：把奖励与代价同时定价。

## 核心机制

五张情绪模块卡（`剧情/情绪模块.md`），每张都是"缺口→加压→触发→爆发→余波"的完整情绪链。

- **EM-001 上交后置结算。** 缺口是拿到了却换不来承认；加压是成果不可自证、来源被怀疑；触发是专业方读懂并给出高定级；爆发是震动发生在组织层、资源反向回流；余波是变成可核对的长期账户。戏剧单元是"一人持有一件无法自证的成果 → 组织投入鉴定成本 → 定级落地 → 结算以非现金形式到账 → 主角拿到下一轮资本且该资本同时强化组织"。成立条件三条：主角无议价权且自愿上交、组织有独立议价能力与保密动机、定价方与主角分属不同专业。复现到新书时至少要替换掉成果载体、定价方、结算形式三项中的三项。
- **EM-002 惩罚即倒计时与组织抢答。** 缺口是时限明确且失败不可逆牵连他人；加压是奖励不可读、要求与自身能力严重错配；触发是主角把期限压力转译给组织换资源；爆发是组织投入超规格资源办成不可能；余波是代价被换算到具体的人与家族。失效情形有两条要防：惩罚从不落地会退化为口头威胁；组织总能兜底则成长让位于组织。
- **EM-003 张弛对冲：高压段后的日常承接。** 情绪链最特别的一点是"爆发"位不设爆点，改为能力与账户静默增长，然后"余波"位在最平静处埋一个尚未解释的异常。承载载体是招人、经营、采购、吃饭。失效情形：日常段与主线资源脱钩会变注水，连排两段日常期待感断档，埋线被提前解释则失去张力。
- **EM-004 误会让身份变得更强。** 戏剧单元是"身份不足者被当众轻视 → 一名中立第三方去查 → 数据被对方拿来自我解释 → 全场改口 → 组织顺势把误会加固成正式说法"。主角全程沉默仍完成压制，是最省笔墨的优越感兑现。最大风险：同一误会连用两次会失效；截至第343章这套假身份仍未被戳破验证过。
- **EM-005 代价由配角支付并由组织定价。** 前置铺垫极重——先给配角姓名、动机与家人；爆发位放在追授或安葬的具体场景；余波不是结清而是把亏欠转成下一阶段的行为动机。失效情形：牺牲若无铺垫会变廉价催泪；只发牌匾不安置家属会被读作敷衍；连续使用会滑向"献祭—表彰"循环。

五张卡的共同点：**爆发点一律不在主角身上**。定级在私下通话里，赴死与安葬在仪式场景里，被改口的是对手自己，主角的实际动作在全书高压段里往往是"被安排"或"听指令"。

## 可借鉴套路

- **上交国家后置结算。** 把系统文的"独吞奖励"改写成双向兑现，爽感不必靠独占。这是全书最核心、最可迁移的一条。
- **反应层前置。** 主角上报后、动手之前，接盘方先于读者完成判断与资源调度。作用是消除"主角孤证无法自证"的叙事死角。风险：反应层过强会让主角变被动。
- **掉马震惊的预防性使用。** 不让主角被动暴露，由组织提前布一套可自圆的身份工程，把危机提前转成资产。
- **掉马震惊的反向使用。** 主角不解释，由第三方数据或物证让对手自行改口。最省笔墨的优越感兑现。
- **以小搏大（以工程换蛮力）。** 难点交给国家级工程破解，主角只做最后那个不能外包的动作。风险：组织投入过重时，主角的勇气与成长会被淹没。
- **升级试炼的专业化。** 试炼不再是打怪，而是跨过飞行、舞台、深潜等专业门槛。门槛自带可测量的训练量与考核者，成长看得见。
- **迟来追悔的反向使用。** 主角不回来证明什么，而是把家人从被欺负的位置直接搬走，补偿一次到位、不留拉扯；阻力来自真实的阶层恐惧而非恶人太弱。
- **反派收网与代价定价。** 反派结局由执法与档案闭环完成，"恶有恶报"不靠主角单挑兑现。
- **专家承担震惊。** 用内行失态替代路人叫卖，每份奖励都被更高一级机构重新定价，估值只能上行。
- **日常经营承接。** 用低烈度经营段完成资源到账与关系推进，是"上榜收益"落地的必要装置。

**复现时的四条纪律**：先选读者需求再选模块卡，不要从原文桥段倒抄；保留情绪链和功能位，替换人物、场景、动机、道具、事件素材；复现到新书大纲时至少改变冲突对象、公开/私密场景、触发证据、余波方向中的三项；人设与模块冲突时以人设驱动重构，不要为套套路扭曲角色。

## 写法技巧

- **让主角向现实机构解释网文设定。** 把"系统"这个类型化名词丢给一个不读网文的中年干部，一次对话同时完成世界观交代、喜剧效果和"主角孤立无援"的处境塑造，三件事一笔办完。
- **用现实世界的保密等级给信息定级。** 不写"系统信息很厉害"，只写"这是国家最新一代主战坦克，各国情报部门都在盯着，现在还在小规模列装测试中，并没有公布"。一句话让系统的分量落地。
- **让配角的内心推演承担信息量和爽感。** 第2章约450字的"算风险收益"同时讲清了国家为什么要帮一个疯子、把陈卓的专业性立住、让"国家帮助主角"变得可信。慢热文里这笔墨花在配角判断上比花在主角展示上更省字数也更可信。
- **把"证明自己"写成一场有干扰的测试。** 干扰层层加码，读者跟着配角一起怀疑、最后一起被打中；而且主角与读者都暂时看不懂配角在干什么，这个悬置段本身就是阅读动力。
- **验证之后给"值得赌"而不给"我信了"。** 只把100%不可能改成99%不可能，让信任成为一条可以慢慢走的线，避免前期把关系拉满、后面无处可写。
- **一个道具办三件事。** 全封闭头盔同时制造生理不安、解释语音指令的合理性、并让"听懂就闭嘴"这个给主角加分的细节得以成立。
- **靠配角的意外反应给主角加分。** 不让主角说"我明白"，让配角心里惊讶"能迅速明白自己处境并接受，不是所有人都有的能力"。
- **先降心率再爆发。** 把高潮从肾上腺素改成"按流程执行"的笃定，适合主角第一次正式出手的场面；代价是爆发感下降，必须后置一个反应镜头补回来——本书恰好漏了这一步。
- **不解释制度，让角色按制度说话。** 一段口述的审批报告就能让读者自己听出制度长什么样。
- **把内心推演写成可复述的决策逻辑。** 赌不赌、赌多少、赌输的后果，都在一段内心戏里交代清楚，读者服气。
- **让配角承担代价，主角承担余波。** 周哲之死之后没有立刻复仇，先给救援、先给遗愿、先给安葬——牺牲章后立刻报复会消耗掉整段情绪。
- **用规格与外部视角抬高成果。** 机型报价、养护成本、证件编号是规格本身；虎牙长文与 DIA 地下会议室用公开信息推出外骨骼代差，比作者自己夸更有说服力。

## 不建议模仿

- **不要抄"前三章没有爽点"。** 三章合计只有憋闷没有回甘。第3章反应篇幅比 0.36:1 是明确的结构缺陷，不是风格选择。同样的慢热可以保留，但第一次小释放应该提前到开篇600字内，并至少补一个当场反应镜头。
- **不要抄主角前期的彻底被动。** 前三章李策零自主决策，连最后的漂移都是听指令完成的，连开坦克这件事本身也不是他自己争取来的。作者自述这是成长起点的有意设计，但抄过去就只剩"主角被推着走"。
- **不要抄"永远不给答案"的悬念处理。** 被遮挡模块、系统来历、三种模型、"我们是否在某本小说里"四条线全部悬置到第343章仍未兑现。技术谜团可以压着不解，系统谜团压四条就接近过载。
- **不要抄松散的家庭线。** 前期家庭线只有母亲一句台词和一个未展开的父亲伤情，中段才用"父亲不给你找麻烦就是最大的帮助"把愧疚补齐。亲情线如果不在前50章内给足一次完整的情绪兑现，读者会认为它只是工具。
- **不要抄同一套误会的反复使用。** 掉马震惊的反向使用需要持续的外部数据源供给，连续使用会钝化。本书靠每个单元换一个圈子（新公司/二代圈/剧组/矿区/会所）来续命，这套换场成本很高。
- **不要抄作者随笔插章。** 第48章（1253字）、第77章（1455字）、第230章（171字，纯作者留言）三次插在高压段中间，会直接切断阅读惯性。
- **不要抄用"字数"替代"情绪"的奖励描写。** 参数罗列、装备清单、成本明细用得极有效（第74、140、286章），但一旦连续两段都靠清单推进而不给一个人物反应，就会退化成设定展示。
- **不要抄对配角年龄、职级、籍贯的长期留白。** 陈卓的职级只能由"陈主任""第一接触人"反推，苏晴与王红旗孰正孰辅始终没有分工规则，两位安保在几百章里始终只有"苏晴姐""王神"两个称呼。对慢热文来说这层留白可以省字，但对情感浓度是直接扣分。

## 文风一句话

**用国家机器的办事流程替代主角光环，用机构的专业克制替代情绪外放，把"一个人的绝境"翻译成"一个单位的调度"，读起来像一份带着心跳的立项报告。**

### 本阶段偏差披露


- **剧情数量检查为不通过。** 实际 43 个剧情单元，规范引导是"超过300章 → 15-40 个"，超出上限 3 条。理由：本书是"一个系统任务约等于一个相对独立单元"的高密度结构，343 章内出现约20个系统任务/结算节点，非洲线（第192-240章）与鳌太线、深潜线各自跨度11-14章且内部四要素齐全；若压到40以内，只能把"鳌太线任务的准备／鳌太线穿越与视频发布"这类"准备—执行"连续任务强行合并，会损失阶段区分与"独自"判定这一关键解法。照实保留 43 条。
- **42 个剧情单元的「概要」超出规范 150-300 字**，实际落在 280-1493 字区间，其中明祖陵锁龙局单元为 1256 字。这是逐章提取阶段形成的偏差，本阶段选择**如实保留并披露**，不做强行压缩——压缩会丢掉国家工程破解与人物关系走向这两条下游最依赖的信息。
- **5 份角色档案的六节正文超出 500 字规范**（占 46 份完整档案的 11%），最长 裴舒晚 612 字。超出来的是人物的完整经历与关系走向，压缩后会丢掉下游最依赖的「这个人做过什么、跟谁什么关系」。照实保留并披露。
