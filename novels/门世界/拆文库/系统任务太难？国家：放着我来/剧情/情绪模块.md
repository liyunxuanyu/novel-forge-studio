## 故事框架与套路运行图

| 框架/套路 | 在本书中的位置 | 运行方式 | 为什么有效 | 失效风险 |
|---|---|---|---|---|
| 上交国家后置结算 | 每次奖励结算的后半段：第4-8、106-109、121-123、138-147、285-290章 | 主角先交出成果，组织再定价，并以非现金形式回流 | 把系统文的"独吞奖励"改写为双向兑现，爽感不必靠独占 | 组织若无议价能力，回流会退化成施舍，主角变成被资助者 |
| 惩罚即倒计时 | 任务一经下发：第1-3、266-273、320-326章 | 面板给出时限与牵连范围，失败即抹杀宿主及三代血亲 | 时间成为唯一硬约束，所有准备工作都有价格 | 惩罚始终只在口头升级而未真正执行，热度会衰减 |
| 反应层前置 | 任务上报后、主角动手前：第1-3、73-78、327-334章 | 接盘方先于读者完成判断，把系统的解释权转移给组织 | 消除"主角孤证无法自证"的叙事死角 | 反应层过强会让主角变被动，削弱个人解题的乐趣 |
| 掉马震惊的预防性使用 | 第68-78章的白手套、241-245章的特招入伍、320-326章的脑补 | 不让主角被动暴露，由组织提前布一套可自圆的身份工程 | 危机被提前转成资产，误会越深越安全 | 谎报一旦被戳破回收代价极高；截至第343章仍是未验证风险 |
| 掉马震惊的反向使用 | 第31-43、91-100、291-300章 | 主角不解释，由第三方数据或物证让对手自行改口 | 主角全程沉默仍完成压制，最省笔墨的优越感兑现 | 连续使用会钝化，且需要持续的外部数据源供给 |

| 升级试炼的专业化 | 第124-137、148-157、327-334章 | 试炼不再是打怪，而是跨过飞行、舞台、深潜等专业门槛 | 门槛自带可测量的训练量与考核者，成长看得见 | 专业细节一旦失真，读者会从膜拜转为挑错 |

## 可复现模块卡

### EM-001 上交后置结算

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 交出去的东西没白交，反而换成更值钱、更长期的东西回来 |
| 情绪链 | 缺口（拿到了却换不来承认）→ 加压（成果不可自证、来源被怀疑）→ 触发（专业方读懂并给出高定级）→ 爆发（震动发生在组织层，资源反向回流）→ 余波（变成可核对的长期账户） |
| 戏剧单元 | 一人持有一件无法自证的成果 → 组织投入鉴定成本 → 定级落地 → 结算以非现金形式到账 → 主角拿到下一轮的资本，且该资本同时强化组织 |
| 关键触发物 | 一个外行无法评价、只有特定专业身份才能定价的成果载体 |
| 必要铺垫 | 先让读者相信成果为真（物证、可复现细节），并留出"组织尚未介入"的空白 |
| 成立条件 | 主角无议价权且自愿上交；组织有独立议价能力与保密动机；定价方与主角分属不同专业；读者已知组织的资源量级 |
| 复现步骤 | 1. 建缺口 2. 加反应层（安排不懂行的中间人先慌） 3. 控制爆发点（最高定级放在私下通话而非公开场合） 4. 立新钩子（结算形态超出主角预期） |
| 可替换项 | 成果载体→任何外行无法定价的专业成果；定价方→任何具备专业判断力的组织或个人；结算形式→任何长期资源（现金/实物/编制/权限）；上交对象→任何强于主角的组织 |
| 不可照搬 | 具体技术名词、机构与职务名称、实体载体、专家失态等标志性桥段与台词 |
| 失效情形 | 换掉组织议价能力后结算变成施舍；抽掉外行中间人则震惊无处发生；定级提前公开会让爆发点失去落差 |
| 反例/边界 | 奖励栏长期乱码、奖励类型多次未标，结算价值只能靠读者推断；第343章仍在连载，结算线未收口 |
| 关联节奏 | `剧情/节奏.md` RH-002（第4-8章 U盘无人能读）、RH-015（第229-240章 退伍两年难追授）——释放位，宜紧接一次短日常段消化 |
| 证据来源 | 技术验证与高层决策 第4-8章；紧急任务结算与技术选择 第106-109章 |

### EM-002 惩罚即倒计时与组织抢答

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 一块随时会砸下来的硬期限，逼着所有人一起动起来 |
| 情绪链 | 缺口（时限明确、失败不可逆且牵连他人）→ 加压（奖励不可读、要求与自身能力严重错配）→ 触发（主角把期限压力转译给组织换资源）→ 爆发（组织投入超规格资源办成不可能）→ 余波（代价被换算到具体的人与家族） |
| 戏剧单元 | 个人无法完成的限期任务 → 主角把期限压力转译给组织 → 组织分兵对接多个系统 → 任务以超常规规格完成 → 主角获得能力，代价记在别人账上 |
| 关键触发物 | 一个主角无力独自完成、而组织恰好拥有对应能力的任务 |
| 必要铺垫 | 先让读者相信惩罚会被执行；先给组织一份完整资源清单；把主角的能力短板量化 |
| 成立条件 | 惩罚不可逆且外溢至主角在乎的人；组织有能力并愿意跨界调度；主角接受"自己的命是别人的赌注"这一关系前提 |
| 复现步骤 | 1. 建缺口（先给一次轻松任务建立节奏） 2. 加反应层（接盘方先于读者开始质疑） 3. 控制爆发点（最大投入压在任务当天） 4. 立新钩子（惩罚范围向上扩一级） |
| 可替换项 | 惩罚形式→任何不可逆且牵连他人的代价；时间压力→任何明确的短时限；接盘方→任何在主角之外早于读者反应的机构；超规格资源→任何与任务类型匹配的硬件或编制 |
| 不可照搬 | 原样照搬的抹杀与血亲范围、具体军种番号与装备型号、面板的乱码与字体表现 |
| 失效情形 | 惩罚从不落地会退化为口头威胁；组织总能兜底则成长让位于组织；时限过短会跳过准备段，节奏塌陷 |
| 反例/边界 | 血亲范围的升级只由模型推算，规避婚期的方案对策小组自己也误判，属未验证设定 |
| 关联节奏 | `剧情/节奏.md` TR-001（第1章 系统绑定与抹杀倒计时）、RH-001（第1-3章 7小时36分倒计时）——加压位，宜与短日常段交替，不可连续排布 |
| 证据来源 | 坦白与坦克漂移 第1-3章；升级任务：驾歼-20 飞越宫古海峡 第124-137章 |

### EM-003 张弛对冲：高压段后的日常承接

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 刺激看够之后，有人陪我过几天普通日子 |
| 情绪链 | 缺口（高压刚结束，需要缓冲）→ 加压（日常内部仍埋着失控/合规/穿帮隐患）→ 触发（招人、经营、采购、吃饭等低烈度事件推进）→ 爆发（不设爆点，改为能力与账户静默增长）→ 余波（最平静处埋的异常成为下一段引信） |
| 戏剧单元 | 高压收束 → 进入低烈度日常 → 日常中同时完成能力消化、资源到账与关系推进 → 在最平静处埋一个尚未解释的异常 → 异常变成下一段引信 |
| 关键触发物 | 一个让读者与主角都不必紧张、却必然产生新信息的低烈度事件 |
| 必要铺垫 | 读者必须先经历足量高压才会把日常当奖励；组织的手（审批、备案、上报）在日常里仍要可见 |
| 成立条件 | 作者能稳定维持两套强度档位；日常段与主线共享同一套资源账户；异常线索允许长期不解释 |
| 复现步骤 | 1. 建缺口（高压段刚结束） 2. 加反应层（让日常配角带着与主线相关的诉求入场） 3. 控制爆发点（真正爆点压到下一段开头） 4. 立新钩子（异常只出现一次，不解释） |
| 可替换项 | 日常载体→任何低烈度但有信息增量的活动；配角诉求→任何能顺手牵出主线资源的需求；埋线功能位→任何可延迟引爆的不确定项 |
| 不可照搬 | 具体公司业务与产品设定、具体备案与审批机构、具体对话与笑点 |
| 失效情形 | 日常段与主线资源脱钩会变注水；连排两段日常期待感断档；埋线被提前解释则失去张力 |
| 反例/边界 | 全书节奏比例由情节点统计推断，个别长单元内部并未严格交替；公司线多个节点仍处开放状态 |
| 关联节奏 | `剧情/节奏.md` RH-010（第110-116章 台风）→ TR-008（第73-74章 直升机转院）的对冲结构；本书节拍层，定义在每个高压段之后 |
| 证据来源 | 「聆听」训练与公司总部落地 第179-191章；柳柳入职与教育部攻关 第316-319章 |

### EM-004 误会让身份变得更强

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 他一句都没解释，所有人却自己把他想得更高级 |
| 情绪链 | 缺口（主角没有对外身份，被当成攀高枝）→ 加压（对方轻蔑、试探、当众设套）→ 触发（第三方数据在现场出现）→ 爆发（全场自行改口，误会比真相更保护他）→ 余波（误会沉淀为通行证，戳穿风险同时累积） |
| 戏剧单元 | 身份不足者被当众轻视 → 一名中立第三方去查 → 数据被对方拿来自我解释 → 全场改口 → 组织顺势把误会加固成正式说法 → 主角带着假身份继续生活 |
| 关键触发物 | 一份可被现场第三方查到、且恰好支持更高猜测的公开数据 |
| 必要铺垫 | 先确认主角确实没有可用身份；对手必须自信到敢当众设套；组织随后接手加固 |
| 成立条件 | 假身份需要官方背书才能通行；对手的信息渠道真实存在；误会必须对主角的安全确实有利 |

## 重组与复现指南

1. 先选读者需求，再选模块卡，不要从原文桥段倒抄。
2. 保留情绪链和功能位，替换人物、场景、动机、道具、事件素材。
3. 复现到新书大纲时，至少改变：冲突对象、公开/私密场景、触发证据、余波方向中的三项。
4. 若人设与模块冲突，以人设驱动重构模块；不要为了套套路扭曲角色。
